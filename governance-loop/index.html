SIMULATION - REFERENCE IMPLEMENTATION - NOT THE PRODUCTION LOOP

Integrated Governance Loop

One claim, run through all three governance pieces in sequence: N-Cell/64 header, governance intersection, memory write-gate, CRUCIBLE gate, receipt, promotion. The loop is visible end to end.

What this is: a working reference implementation that wires together the three modules built earlier in this run: the N-Cell Organ Manifest header stamper, the memory write-gate, and the P0 seam loop (receipt watcher, Sentinel, ingest, promotion). It enforces nothing in production, routes nothing, and grants no authority.

What this is not: the production loop. The production loop lives on Jeramie Hicks' Mac. Nothing on this page touches it, reads from it, or claims to be it.

Receipt standard: receipt v1.0, SHA-256 hash chain, first prev hash is the literal string GENESIS, canonical JSON with the hash field stripped before hashing. FNV-1a is used nowhere. Bit meanings are the N-Cell demo placeholders and manifest mappings, never paper claims. Memory-gate thresholds are illustrative; the paper sets none.

1. The loop, in order

  1. Step 1, header. Stamp an N-Cell/64 header, paper Section 3.3: 8 bytes, routeMask, organMask, lifecycleMask, authorityMask, memoryMask, confidence 0-255, risk 0-255, outputMask. The paper defines the layout only and sets no numeric defaults. Defaults here are the Organ Manifest demo defaults: confidence 128, every other byte 0, organMask 0x07 (SAL manifest bits 0, 1, 2).
  2. Step 2, intersection. E* = E_proposed AND E_allowed AND E_available, paper Section 3.4, computed on edge id sets. Verdicts: NO PROPOSAL (proposed empty), BLOCKED (intersection empty), PARTIAL (some proposed edges lost), PROCEED (intersection equals proposed). Defaults: propose 8, allow 6, available 5, intersection 5, PARTIAL.
  3. Step 3, memory write-gate. The claim's evidence answers the 8 gate questions (class, source, freshness, confidence, contradiction, relevance horizon, fact vs inference, immutable history vs editable current state). Illustrative rule: evidence below 3 REJECT, contradicts QUARANTINE, evidence below 6 QUARANTINE, else WRITE. The paper sets no numeric thresholds.
  4. Step 4, CRUCIBLE gate. Score = max(0, emergence - objections) x multiplier. Ladder: revenue/signed contract 1.00, paid pilot 0.50, one real lead 0.30, nothing 0.15. KILL below 20 or 3 strikes, ITERATE 20-49, SHIP-CANDIDATE at or above 50 only with a real external signal.
  5. Step 5, receipt. A receipt v1.0 is emitted recording the header, the intersection verdict, the gate verdict, and the CRUCIBLE verdict, chained from GENESIS.
  6. Step 6, promotion. Only a claim that passes all three gates AND carries a real external signal promotes. Otherwise it stops, and the blocking gate is named.
