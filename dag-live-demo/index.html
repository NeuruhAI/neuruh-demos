    Presenter script

    Six moves that show the whole system in about three minutes.

    1. Load DAG A with the seam set to “Handoff missing.” Run it. The mission stalls at receipt.sealed and waits for the founder. That stall is the current P0 continuity defect, live.
    2. Approve the Work Spec gate. Authority is one of the few legitimate founder touches. Watch the event log: every node emits its receipt as it fires.
    3. Flip the seam to “Handoff repaired” and re-run. The mission now crosses receipt → Switchboard → court with no courier duty, and the predicate strip fills stage by stage.
    4. Set the court verdict to FAIL and re-run. Execution halts at the Independent Sentinel. Custody, promotion, and delivery never happen.
    5. Inject a stop condition mid-run. Provider limit, receipt-chain break, scope expansion: the graph halts on the spot, at whatever node it reached.
    6. Run the organism chain A → F → H. Execution, then learning, then public-safe proof. When all eleven predicate stages are lit, one bounded target has crossed the whole system.

    Convergence hubs

    The six systems every DAG plugs into. A node that cannot name its hub is not wired into the graph.

    • Organ registry
      Every organ and worker the DAGs can call, addressed in one registry.
    • Current gates
      Court, governance, and promotion authorities that no node may bypass.
    • DeedSonar
      The flagship surface where the opportunity DAGs land as decisions.
    • Commercial proof
      Public-safe proof feeding offers, intake, fulfillment, and delivery.
    • Runtime promotion
      Custody, merge, deploy marshal, and semantic verification.
    • Learning
      OutcomeRecords and calibration that change the next mission.

    Founder attention boundary

    Founder input belongs at exactly six points. Everywhere else, the founder is load the system should not need.

    Input only at

    • objective
    • consequence
    • joint business authority
    • ambiguous canonical conflict
    • legal / financial commitment
    • irreversible / destructive action

    Never as

    • receipt courier
    • session memory
    • PR scheduler
    • runtime watchdog
    • handoff transport
