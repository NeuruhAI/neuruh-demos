Case Zero: protocol, controls, scoring, ablations

Handoff sections 21 to 25. The largest threat to the Jeramie/Neuruh interpretation is hindsight bias: after Neuruh exists, almost any earlier life experience can be made to look prophetic. Case Zero was designed specifically to eliminate that loophole.

Primary research question: Can independently coded relational structures from Jeramie's dated pre-AI corpus predict material features of the later Neuruh architecture above reasonable baselines and controls?

The 13-step protocol

  1. Lock temporal cutoff and historical epochs.
  2. Inventory and hash all relevant sources.
  3. Remove post-cutoff contamination.
  4. Blindly extract conceptual/relational atoms without using later Neuruh terminology.
  5. Construct a latent-schema graph.
  6. Generate architecture predictions.
  7. Seal those predictions.
  8. Independently code post-AI outcomes.
  9. Match predictions against outcomes under blinded conditions.
  10. Run domain ablations.
  11. Run control corpora.
  12. Score results.
  13. Produce one of: provisional support; narrowed support; inconclusive; rejected; reframed.

Required controls

Generic entrepreneur corpus; narrow AI-specialist corpus; random multidisciplinary corpus; shuffled or temporally corrupted Jeramie corpus; one-domain-at-a-time ablations; blinded independent outcome coding; blinded match scoring; preservation of failed predictions; preservation of negative evidence. If controls perform equally well, LCDE weakens substantially. That is intentional. A good theory must risk being wrong.

Scoring dimensions

Temporal lead; structural match; specificity; coverage; false-positive rate; surprise; multi-domain dependence; rater agreement; ablation impact; control advantage.

What is not done: P0, P1, P2

Handoff sections 47, 48 to 54. This is where the next chat should focus. The theory does not need another 100 pages before the evidence engine exists.

P0: Build the evidence pipeline

Collect the relevant historical corpus; hash it; preserve original paths; preserve timestamps; establish immutable registry; establish historical epochs; identify contamination boundaries; normalize without destroying originals.

P0: Execute Case Zero

Define temporal cutoff; establish pre-AI corpus; establish post-AI outcome corpus; assign blinded extraction methodology; induce pre-AI schemas without Neuruh terminology; seal predictions; independently code Neuruh; match; score; ablate; run controls; publish failures as well as successes. Until this exists, LCDE remains hypothesis.

P1: Complete the living canon

Source registry; canonical ontology; alias registry; contradiction registry; decision ledger; confidence; temporal history; supersession relationships; provenance links; claim lifecycle. Every important principle should answer: where did this originate, who said it, when, what supports it, what contradicts it, what version is current, what replaced older versions, what evidence would reject it.

P1: Build hybrid retrieval

Dense retrieval; sparse retrieval; reranker; temporal weighting; canonical confidence; contradiction penalties; evidence expansion; task-aware context compilation. Then evaluate retrieval against real historical questions.

P1: Create training data and preference data

500 to 2,000 approved supervised examples for the first jeramie_core adapter, representing reasoning patterns, preferred structural outputs, evaluation behavior, evidence discipline, decision style, and compression/expansion behavior. Facts/history should mostly remain externally attributable. Preference pairs from accepted edits, rejected outputs, deployments, revenue results, avoided loss, rework, governance failures, and successful predictions.

P1: Actual domain adapters

Only after core evaluation: adaptive intelligence; real estate; resale; defense; content/IP; FounderOS; governance; archive reasoning. Do not train everything simultaneously. Maintain modularity.

P2: Visual instrumentation and prior-art review

Implement the designed views, especially polarity phase space, emergence instrument panel, semantic topology, contradiction timeline, archive pipeline, Case Zero dashboard, cross-domain transfer matrix, and experience-to-asset graph. Before any serious scientific novelty claim, systematically compare against cybernetics, predictive processing, active inference, reinforcement learning, schema theory, analogical transfer, transfer learning, continual learning, developmental psychology, dialectics, complexity science, emergence literature, desirable difficulty, antifragility, organizational learning, knowledge representation, and memory systems.
