Two-spine strategy, Obsidian and Bone

Dark is not "the Neuruh look." The two spines split the work:

Obsidian spine

Depth, authority, cinematic environments, diagnostics. High-density operator work, system state, and control.

Bone spine

Evidence, explanation, editorial surfaces, reports, client-facing systems. Evidence reading, detail views, explanation panels, provenance, receipts, and decision surfaces.

Why it matters

The split prevents everything from becoming another black hacker dashboard. The Lead Recipe OS rebuild is explicitly told: do not make everything black.

Figure 3. Two-spine strategy, turn 1 item 5. This page itself follows the Bone spine: editorial surfaces for evidence and explanation.

Material, motion, and the anti-patterns

Material strategy

Physical, architectural, mineral, engineered. Not glossy generic SaaS. Surfaces should feel like machined plates, mineral, paper/bone, brushed metal, membranes, evidence artifacts, with real depth that has semantic purpose.

Evidence and governance are part of the design language

Provenance, contradictions, confidence, authority boundaries, receipts, and system states are not backend concepts hidden in logs. The interface is designed to make them visible.

Motion has meaning

Recognition, organization, contradiction, gating, execution, receipt, adaptation. No random floating decoration just because WebGL can do it.

Explicit anti-patterns, actively rejected

Visual cliches

Generic glowing AI orb. Brain / neural-network imagery. Galaxy graphs for decoration.

Seven specific problems and deliverables A to G

Specific problems to solve in the current UI

From the current screenshots, assume the following problems are real unless code proves otherwise:

  1. Visual hierarchy is weak: too many same-value dark surfaces, insufficient contrast, everything reads like one flat pane.
  2. Semantic overload is poorly organized: many chips and labels, technically present but cognitively noisy.
  3. Evidence, predicates, and next-best-action are under-designed: conceptually powerful but visually underpowered.
  4. Information density is not strategically tiered: operator density is good, but cramped rather than composed.
  5. The page feels like a raw internal tool instead of a governed operational surface: "capital-grade instrument panel," not "developer dark screen."
  6. State expression is inconsistent: granted / denied / unwired / not evaluated / evaluated need clear, repeatable semantics; chips alone are not enough.
  7. The current screen does not yet embody the biological-architectural thesis: needs stronger system structure, circulation, and controlled material presence.

Required deliverables

A. Audit report

Concise but thorough audit of: current visual system, component inventory, token usage, hierarchy failures, accessibility issues, density issues, state semantics issues, spacing issues, typography issues, missing seams between operator workflow and visual system.

Rebuild directives, execution, acceptance, output format

Nine rebuild directives

  1. Restructure the page shell: clearer top hierarchy, stronger title region, visible distinction between system state, entity context, and actionable evidence.
  2. Rework the signal / header band: discipline the top chip cloud into an intentional band, key operational state first, blockers next, adapters grouped logically.
  3. Rebuild the detail view as a governed instrument panel: overview, decisive state summary, predicate matrix, execution chain, evidence / score / provenance, next best actions, independent axes and contact readiness, receipts and attribution.
  4. Introduce Bone strategically: evidence panels, explanatory panels, receipts, selected detail panes, provenance drawers, review modules.
  5. Make state semantics unmistakable: granted, denied, verified, unwired, not evaluated, unknown, active, blocked, production write denied, callable / non-callable, fixture mode.
  6. Improve table and list ergonomics: stronger row rhythm, better header contrast, clear entity / asset / stage relationships, restrained accent.
  7. Preserve density without ugliness: operator density kept, with clearer groupings, spacing tiers, typographic hierarchy, nested layers, deliberate alignment, reduced noise.
  8. Make receipts and evidence feel premium: evidence is a first-class system asset, valuable operational currency, not incidental metadata.
  9. Keep the interface honest: no fake charts, no meaningless trend lines, no decorative intelligence motifs, no ornamental 3D nonsense inside the operator UI.

Code execution expectations

Step 1 inspect, Step 2 plan, Step 3 implement, Step 4 retest, Step 5 connect missed seams, Step 6 verify live, Step 7 receipt. Work like an implementation engineer, not a moodboard artist. Do not claim done without visual confirmation.

Required acceptance criteria

The work is not complete unless: the new UI clearly aligns with the Master Design System; the screen no longer reads like a generic dark dashboard; dense operator utility is retained; evidence, governance, authority, predicates, and receipts are visually legible and strategically pri [truncated in browser view]; Obsidian and Bone both appear meaningfully; brass is used sparingly and semantically; typography roles are correct; semantic state treatments are consistent; key screens are visually more premium, more legible, and more trustworthy; no major route or feature regressions; all tests possible in the environment were run and reported; final screenshots and implementation receipt are produced.

Output format required from the execution model

  1. Audit summary
  2. File-by-file implementation plan
  3. Changes made
  4. Tests run + results
  5. Seams connected
  6. Live verification notes
  7. Final receipt
  8. Remaining issues, if any

What to tell it not to do

Do not: invent random brand colors; make everything glossy or neon; turn this into a consumer SaaS dashboard; remove dense operational information; bury evidence; collapse important system states; use decorative 3D or AI tropes; skip testing; skip live verification; claim completion without a receipt.
