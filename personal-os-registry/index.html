3. Asset record generator

Build a PersonalOS_AssetRecord exactly per the schema. UUID is deterministic from the URI (UUIDv5-style SHA-1), SHA-256 is computed in-browser when you pick a file. Nothing leaves the browser.




4. Query protocol


  1. Domain scoping. Identify the target domain namespace (10_NEURUH_SYSTEMS, 20_DATA_PIPELINES_GIS, etc.).
    2. 

  2. Priority filtering. Default search scope is P0_IMMEDIATE_CONTEXT and P1_ACTIVE_PROJECT only, to prevent context bloat.
  3. Exact node resolution. Map the file URI to its physical or cloud storage node before dispatching execution commands.
  4. Dependency check. Resolve dependent configs in 00_CORE_OPS before invoking local scripts.
