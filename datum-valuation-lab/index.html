1. What DATUM is

DATUM is a valuation product beside LandOS, not a rebuild of the LandOS model. LandOS scores acquisition likelihood. DATUM values a parcel: what is this dirt worth, with a distribution, not a point. Codename datum: a datum is the fixed survey reference point every other measurement derives from. Tracked as Q-007 in the repo.

The architecture is a DAG, not eight independent specialists. Fan-out happens exactly once, at Layer 1 (fact extraction). Everything downstream has explicit dependencies, and there is a single writer per adjustment: no two modules may touch the same dollar.

LayerNameFunction
0Subject resolutionParcel ID, geometry, acreage, use code, improvement record. Deterministic. Code, not prompt.
1Fact extractionThe only genuinely parallel layer. Regulatory, infrastructure, physical, market pullers.
2Feasibility solverEmits the feasible use set. Only this layer may state what is buildable.
3Subtype routerFeasible use set plus improvement record selects the pricing engine.
4Valuation enginesPure Python. No LLM arithmetic, ever. Takes calibration coefficients as an argument.
5CalibrationVersioned JSON artifact of fitted coefficients, keyed by geography x subtype, hash-stamped.
6ReconcilerFires only when engines disagree beyond a threshold. LLM judgment, disagreement made explicit.

2. The label tiers 0 to 4

Calibration is the oven thermometer, not an ingredient. It is measured, not seasoned. It has a ground truth, and it gets recalibrated when the oven drifts. The label hierarchy has different latencies, volumes, and trust weights. Most of it is observable, free, and already exists.

TierNameWhat it isTrust role
0Hard labelsRecorded arm’s-length sales. Indiana Sales Disclosure Form (Form 46021): price, date, conditions of sale, explicit arm’s-length flags. Field P2_16_Valid_Trending is the county assessor’s own adjudication that a sale is valid for trending, a professionally determined arm’s-length flag, not a filer self-report. Free direct download at stats.indiana.edu, back to July 2008, refreshed weekly.Highest. Drives the fit. The target variable.
1Weak labels at scaleAssessed values, used as a ratio. Never fit to assessed value. Fit the ratio of sale price to assessed value (sales-ratio study, IAAO standards: COD for uniformity, PRD for regressivity). Field P2_5_Total_AV is assessed value at time of sale, so the ratio study needs no second dataset.Supplies the geography multiplier.
2Market signalsList price, days on market, list-to-sale ratio, withdrawn/expired, price cuts. Noisier than sales, but abundant and 3 to 12 months ahead of recorded sales.Corrects for recency.
3Operation outcomesOffer $X. Accepted or rejected. A censored observation: accepted at $X means true value is at or below $X; rejected means true value is above $X. Censored regression / survival analysis.Accumulates and eventually dominates. The only tier measuring decision quality.
4JudgmentTwo legitimate roles only: (a) define the feature space, not the coefficients; (b) pairwise preference labels, never “what is this worth,” ask “which of these two is worth more, and roughly by how much.” Bradley-Terry / learning-to-rank. 200 pairwise comparisons is an afternoon of work.Shapes the feature space, supplies the ranking scaffold, then decays as Tiers 0 and 3 accumulate.
Hard rule. Any evaluation run whose test set contains a label you produced is not an evaluation. Holdout must be Tier 0 / Tier 3 only. Your labels train; the world scores. A model fit only to one expert’s labels converges to that expert, can never exceed them, and cannot tell when they are wrong.

3. Interactive: tier classifier

Describe a record. The classifier assigns the highest-trust tier the record supports, and shows the rule it applied. The quarantine check runs first: an assessor-valid flag is not a data-quality guarantee.


RULE (applied top to bottom, first match wins): 1. QUARANTINE: sale price / assessed value ratio at or above 20x, or below 0.05x -> QUARANTINED, never Tier 0. An assessor-valid flag checks market conditions, not whether the number was typed correctly. 2. Sale price present AND assessor-valid arm’s-length AND ratio inside sane bounds -> TIER 0 (hard label). 3. Sale price present AND assessed value present, but not assessor-validated -> TIER 1 (ratio label: sale price / assessed value). 4. Market signals present -> TIER 2. 5. Offer outcome recorded -> TIER 3. 6. Expert judgment only -> TIER 4. 7. None of the above -> NO TIER. Abstention is a first-class return: null plus an evidence gap, never a guess.

5. Interactive: pinball-loss calculator

Not squared error on price. Overestimating by $20k and underestimating by $20k are not equally bad in acquisition. Overpay: you lose real money, unbounded downside on a specific deal. Underpay: you lose the deal, opportunity cost, bounded, you will find another parcel. The loss is asymmetric: penalize overestimation harder than underestimation. Ratio starts around 3:1 (Q-003, a config value, not a constant). Fit three quantiles, P10 / P50 / P90, rather than a point estimate. The output is a distribution; the acquisition decision keys on P10 (what if I am wrong), not P50.

This calculator scores an estimate you supply. It values no parcel. Enter your own numbers; the output is a loss score in the same units, not a valuation.


PINBALL LOSS at quantile tau: if actual >= estimate: loss = tau x (actual - estimate) if actual < estimate: loss = (1 - tau) x (estimate - actual) BUSINESS-WEIGHTED LOSS (this lab): overestimate branch x penalty ratio, underestimate branch x 1. Overpaying loses real money; underpaying loses the deal. Scored separately from accuracy: calibration (when the model says 70% confident, is it right 70% of the time) is measured with Brier score and reliability diagrams. The metric that actually matters is decision quality: of parcels passed on, what fraction later sold above P50; of parcels pursued, realized margin versus predicted.

6. The LLM / Python seam

The rule is not “the LLM writes code that does the math.” That is still LLM-determined math. The actual rule: the LLM emits a feature vector. A versioned, tested, deterministic function maps that vector to dollars. The model’s output schema has no dollar field. It structurally cannot emit a price.

LLM output typeExampleConstraint
Extracted factzoning_district: "AG-1"Must carry evidence_ref (source doc + page/line)
Categorical judgmentroad_frontage_quality: "paved_public_two_lane"Closed enum, no free text
Ordinal judgmentsite_visibility: 3Bounded scale, anchored definitions per rung
Probabilityp_rezone_granted: 0.340 to 1, separately calibrated against outcomes
Abstentionnull + evidence_gap: "no_ordinance_found"First-class, never a guess

Enforced in code: contracts.py, invariant I-1 enforced at import. Add a price field to an LLM-facing contract and the process refuses to start. Reproducibility test: re-run last month’s valuation and get the identical number. Replay the cached feature vector through pinned code and get a byte-identical answer. Every module returns {value, confidence, evidence_refs[], module_version, input_hash}.

The abstention set is the product, not the defect. When the system returns “cannot value, no zoning record found, evidence gap,” that is where mispricing concentrates and competition is thinnest. The gap flag is a prioritized research queue with an estimable payoff. Rank it, work it, exploit the set everyone else’s automation discards.

7. Authority is time-varying: South Bend left the APC

St. Joseph County runs under area planning law: one Area Plan Commission for the county. But the APC does not serve every municipality. The APC’s own staff directory: “Serving St. Joseph County (unincorporated) and the Towns of Lakeville, New Carlisle, North Liberty, Osceola, and Roseland.” The county’s comprehensive-plan RFP is explicit: “The APC does not serve the City of Mishawaka, City of South Bend, Town of Indian Village, or Town of Walkerton.”

An older source (2017 agenda) lists South Bend as APC-served. Both are correct for their date. South Bend left the APC between 2017 and 2023. The exact exit date is open (Q-013). Four independent municipalities need their own ordinance extractions (Q-014): South Bend, Mishawaka, Indian Village, Walkerton.

ADR-0009: jurisdictional authority is time-varying. The label set spans 2008 to 2026. A South Bend sale from 2015 was under APC jurisdiction and the county ordinance; one from 2025 is not. Attaching present-day authority to a historical sale attaches the wrong lot minimums inside the training data, which is worse than being wrong at inference. Michigan has the same exposure: a township can adopt its own ordinance and exit residual county zoning at any time.

Indiana first is confirmed on the label side too: Indiana’s Form 46021 has an arm’s-length flag; Michigan’s Form 2766 has none and the flag must be inferred. Michigan needs a model before it has a label. That is backwards.
