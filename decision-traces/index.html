03 - The triage rubric

A correction becomes a rule only when it clears all three checks. Otherwise it is preserved as context or proposed as a system change, and the trace says so explicitly.

REUSABLE DECISION
Recurs beyond this episode, verified, conditions preserved. Curated into an eval or training case.
SYSTEM GAP
Exposes a missing rule, constraint, or workflow. Proposed as a system change to the ontology, constraints, or workflow.
EXCEPTION
One-off, date-scoped, ambiguous, or a data issue. Preserved as context only. NOT a rule.

Worked examples: the 2026-11-04 Cloudflare deletions are a System Gap (a rule was missing: never delete without explicit per-name approval). The false “Neuruh LLC” name is a Reusable Decision (an eval case: the entity name is Neuruh, never “Neuruh LLC”). The 2026-10-07 repurpose-engine 1-based filename decode is an Exception (it applies only to files dated 2026-10-07 with HHMM before 08:25; applying it to any later date false-positives).
