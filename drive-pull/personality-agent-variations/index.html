Personality Agent Variations

Source: Jeramie's question and the combinatorics worked through in another AI session, 2026-11-18. Numbers verified here by recomputation.

Setup

16 base personality traits (the MBTI-style base types: INTJ, ENFP, and so on). Each base type can carry a subtype, Turbulent (-T) or Assertive (-A), as in INTJ-T and INTJ-A.

An agent is built by combining 2 traits, or by combining 3 traits. Order does not matter; a combination is a set of traits.

Base types only (16 options)

Formula: C(n, k) = n! / (k! x (n - k)!)

  • 2 traits: C(16, 2) = 16 x 15 / 2 = 120
  • 3 traits: C(16, 3) = 16 x 15 x 14 / 6 = 560
  • Total: 120 + 560 = 680 possible agents

With -T / -A subtypes (32 variants)

Each of the 16 base types splits into 2 variants, so there are 16 x 2 = 32 options to choose from.

  • 2 traits: C(32, 2) = 32 x 31 / 2 = 496
  • 3 traits: C(32, 3) = 32 x 31 x 30 / 6 = 4,960
  • Total: 496 + 4,960 = 5,456 possible agents

Refinement: distinct base types only

The counts above include combinations that mix both subtypes of the same base type (for example INTJ-T with INTJ-A). If an agent must combine different base types, subtract those:

  • 2 traits, distinct bases: 496 - 16 = 480
  • 3 traits, distinct bases: 4,960 - (16 x 30) = 4,960 - 480 = 4,480
  • Total distinct-base: 480 + 4,480 = 4,960 possible agents

(The 480 subtracted from the 3-trait count is the number of triples containing both subtypes of one base: choose the base 16 ways, choose the third variant from the remaining 30.)

Open question

The typed combos Jeramie named cannot be computed yet:

  • 1 trait of type #6 and 1 of type #4
  • 1 of #3, 1 of #5, and 1 of #7

These need the group sizes first: how many traits sit in each numbered group (#3, #4, #5, #6, #7). Once those counts are known, the count is a straight product. For example, if group #6 has a traits and group #4 has b traits, the #6 + #4 combo count is a x b. Same rule for the triple: count(#3) x count(#5) x count(#7).
