Framework · Intent Preservation

DaVinci Protocol: Text-Stability Pipeline

Video models smear intent over time. This pipeline locks glyph geometry before motion is applied: typography is rendered once, perfectly, as an anchor frame, and the video model is asked only to read it, never to write it.

Phase 1 · Token Lock

The Typesetter

Orthographic Anchor

Render perfect typography into pixels with a text-accurate image model. Verify spelling, kerning, and edge clarity in a single still frame. That frame is the immutable truth for everything downstream.

Ideogram 2.0 · Flux Pro
Text-to-Image, 4K / 8K still
Phase 2 · Dream

The Animator

Spatial-Temporal Injection

Feed the anchor as first-frame conditioning so the model computes only deltas. Constrain motion to low-magnitude camera and light shifts. No 3D rotations: rotation is where glyphs warp and morph.

Runway Gen-3 Alpha · Luma Dream Machine
Image-to-Video, first frame locked
Phase 3 · Polish

The Polisher

Sub-Pixel Reconstruction

Recover the edge fidelity that low-resolution diffusion and compression spent. Upscale with a refiner tuned for text edges, denoise the high-contrast regions, and interpolate to 60fps for readability.

Topaz Video AI (Proteus / Iris) · Magnific
Upscale to 8K · Interpolate 60fps

Why It Works

Standard text-to-video hallucinates glyphs fresh in every frame, so letters melt. Lock the pixels in space first, then move them in time.

GIBER1SH

Phase 1 · Build the Anchor Prompt

The exact words for the sign, the scene around them, and the look. This prompt goes to Ideogram or Flux, never to the video model.

Then verify: spelling · kerning · edge clarity

Phase 2 · Build the Motion Prompt

Upload the anchor still as the first frame. The motion prompt asks for deltas only, and names the text as untouchable.

Rigid-body motion only · no warp, no rotate

Phase 3 · Polish Settings

The reconstruction pass, in order. Run all three; each recovers a different kind of loss.

  • Upscale to 4K / 8K in Topaz Video AI with the Proteus or Iris model, tuned for text edges rather than faces or foliage.
  • Frame interpolation to 60fps so letterforms hold steady through the motion instead of strobing at 24.
  • Edge-focused denoise on high-contrast regions only; global denoise softens the very edges the pipeline exists to protect.

Operational Guardrails

Production rules from the framework. They are not suggestions; each one maps to a failure already seen in the wild.

  • The anchor typography is the only source of truth. Text is never re-rendered in the video stage.
  • If text degrades: reduce motion magnitude, shorten the duration, or re-run with a stricter “keep text static” instruction. In that order.
  • Prefer rigid-body text motion (translate, scale) over warp or rotate. Perspective rotation is the primary melt trigger.
  • Verify the anchor still before any motion is generated. A misspelled anchor produces a perfectly stable misspelling.
