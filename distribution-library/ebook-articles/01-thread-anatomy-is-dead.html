1/11 Your agent works in the demo and dies in production. The cause is rarely the model. It is the physics of the cache. A field manual, in 11 posts.

2/11 The KV-cache stores key/value tensors for processed tokens. Two requests sharing an identical prefix reuse it. Change the start of the prompt and everything downstream recomputes. Prefix stability is thermodynamics, not style.

3/11 The most common sin: a timestamp in the system header. Cache breaks at token ~15 and a 4,000-token system prompt recomputes every turn. Volatile tokens belong at the tail. Always.

4/11 The three-layer contract. Layer 1: immutable, byte-identical every request. Layer 2: append-only, history only grows. Layer 3: dynamic tail, everything volatile. Violate it and you pay.

5/11 The whole rule in one sentence: no token before the stable prefix may change between requests that should share cache.

6/11 Reasoning and formatting are two different jobs. One pass to think (the brain), a second cheap pass to fill the schema (the mouth). Coupled calls retry. Decoupled calls comply.

7/11 Production failure patterns: the invoice shock (pilot was short, production runs are long), the slow death (turn 80 crawls), the RAG avalanche (full docs prepended, never expired), the schema tax (malformed output, retry loop).

8/11 The audit: diff ten consecutive turns, find the first divergence point, compute your stable-prefix ratio. If divergence starts in the first 10% of tokens, fix that before anything else.

9/11 Measure cost per completed task at p50, p90, p99. Not per token. Per token is a provider metric. Per task is a business metric.

10/11 Build vs buy: buy the commodity (models, compute, vector DBs), build Layer 2 (your memory, retrieval, validation, receipts), sell the outcome. The moat is the architecture no competitor can download.

11/11 This is from "Anatomy Is Dead: The Physics of Building AI That Actually Ships," Book 1 of The Neuruh Papers. More at neuruh.com.
