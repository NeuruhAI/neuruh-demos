Tool 1. Memory Write Gate (Section 34)

Every durable memory write answers eight questions: class, source, freshness, confidence, contradiction, relevance horizon, fact vs inference, immutable history vs editable current state.

Illustrative thresholds: evidence below 3 REJECTS, a contradiction QUARANTINES even at high evidence, evidence below 6 QUARANTINES, otherwise WRITE. The paper gives no numeric thresholds.

Fix note: the Workbench demo coded the quarantine branch as (ev < 6 || type === "Inference" && ev < 6). The second half is subsumed by the first and could never change the outcome, so it was dead code. It is removed here. No new threshold was invented to replace it.

Tool 5. Consolidation Planner (Section 36)

The paper says compress large episodic histories, never delete raw evidence, and create higher-order summaries with backlinks. It gives no scoring formula.

Illustrative rule: importance 7+ and age 30+ days compresses into durable memory; importance 7+ keeps working; importance 4+ and age 90+ days compresses summary only, keeping raw evidence; importance 4+ keeps working; age 30+ days drops the working copy with raw evidence retained; otherwise keep working, review soon. Raw evidence is never deleted.
