03Seller terms

What the seller is actually asking for, in writing. A verbal price is a claim, not a term. Every structure below prices off these numbers.

Amortizing payment: P = PV x r / (1 - (1 + r)^-n), where r = annual rate / 12 and n = term in months. Zero rate means P = PV / n. Every payment on this page uses this formula.

14How it works / What this is not

Read this before relying on any number on this page.

How it works: confirm the parcel from at least 2 public sources, get the loan facts from the lender statement and the note, enter the seller terms in writing, then let the tool price subject-to, seller finance, wrap, lease-option, and hybrid terms from the same rent and cost waterfall. The amortizing payment formula is shown in section 03 and used for every note. A share link encodes the whole deal in the URL so someone else can open the same numbers. Nothing is uploaded.

What this is not: not an appraisal, not legal, tax, or lending advice, not a title opinion, and not a replacement for an attorney, a title commitment, a loan servicer, or lender verification. It does not invent loan balances, rates, payments, or due-on-sale clauses. If a loan fact cannot be verified, it stays unknown and the run is HOLD. A positive cash flow does not mean a deal is good, and a PASS does not mean a property is bad. It means the evidence in this run does not support proceeding on a creative structure. No offer is quoted without Jeramie.

Honest gaps and limits. This tool does not verify a loan balance, rate, or due-on-sale clause against a lender; it only records what was entered and gates on it. It does not model taxes, depreciation, or insurance claims. It does not check state law on wraps, lease-options, or land contracts; those vary by state and need attorney review. Balloon balances assume the note amortizes on schedule with no missed or extra payments. Rent is a single monthly number, not a rent roll. The tool does not check whether a seller is legally able to sell subject-to or whether a loan is assumable. Layout has not been eyeballed in a real browser.

Carried quirks, not silently fixed. (1) Section 07 labels lease-option cash flow as "less underlying payment if buyer pays it", but the 2026-11-04 code never subtracts the underlying payment, and no input records whether the buyer pays it. This build carries the code as written; the label wording is a known mismatch, documented here rather than silently changed, because no stated rule says when the subtraction applies. (2) AUTO kills 1 and 2 (negative cash flow on every structure, negative equity) only run when loan facts are known and the property is not free and clear, so a free-and-clear deal with negative cash flow on every structure fires no AUTO kill. Carried verbatim from the source. (3) Wrap exit uses the wrap note balance, not an amortized balance at exit; seller-finance exit uses the balloon balance only when a balloon month is set. Carried verbatim. (4) The comparison table "Entry cash" for the wrap row shows the seller-finance down payment, as in the source. Carried verbatim.
