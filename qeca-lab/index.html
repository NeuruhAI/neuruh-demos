2a. The three pillars (source claims, not verified facts)

From the QECA product description as pasted 2026-11-03 (source file qeca-source.md). The companion page QECA Equation Check recomputes the description's seven equations by hand; this lab does not repeat that check. It builds the simulator instead.

Pillar 1: Quantum-Driven Reasoning, 5x SOURCE CLAIM

Quantum superposition represents 10^5 decision paths in a state |psi> = sum of a_i(t) |i>, processing complex scenarios in 0.06 seconds, 5x faster than SOTA benchmarks (GPT-4's 1-second response). Governed by a system-driven Hamiltonian (H = -sum J_ij s_i s_j), it collapses possibilities into optimal outcomes without reliance on random or observer-based triggers.

Used in this lab: the superposition form and the 10^5 path count motivate Tool 1, which works the same idea at 5-qubit scale (32 paths) so every step can be shown.

Pillar 2: Emergent Intelligence, 4x SOURCE CLAIM

Layered quantum-classical synergy scales complexity non-linearly, producing self-correcting, adaptive intelligence that mimics emergent consciousness. Reasoning amplifies from 5x to 10x without proportional input, synthesizing disparate data into novel, actionable strategies.

Used in this lab: the feedback loop idea motivates Tool 1's AI feedback rounds and Tool 2's evidence-driven collapse.

Pillar 3: Quantum-Enhanced Efficiency, 6x SOURCE CLAIM

Data compressed at 6x efficiency (75TB to 12TB) using quantum-inspired semantic encoding, secured by 2^128 quantum key distribution (QKD).

Used in this lab: not modeled. No compression or key distribution is implemented here; the claim is shown, not executed.

Deployment claim from the same description: deployable with 20-qubit quantum processors and 300 GPUs. Shown as a claim only. This lab runs on none of that hardware.

3. Tool 1: 5-Qubit Hybrid Simulator with AI feedback

Stated mechanic: a 5-qubit system with AI feedback, run and visualized (Drive doc title, 2025-03-17). 5 qubits give 2^5 = 32 basis states. The demo starts in uniform superposition, then applies AI feedback rounds that favor one target state, then measures. The same seeded run always gives the same result, so any run can be replayed and checked.

BUILDER'S DESIGN. The source states the 5-qubit system and AI feedback; it does not state the feedback math. This lab's rule: each round multiplies amplitude a_i by (1 + strength x (1 - Hamming(i, target) / 5)), then renormalizes. States near the target gain share; distant states lose relative share. The seeded PRNG is mulberry32. This rule is the builder's, not a paper claim and not Jeramie's order.

4. Tool 2: QCM candidate-collapse walkthrough

Stated mechanic (QCM Simulation doc, 2025-03-17, in the QECA folder): maintain multiple candidate pathways and collapse them as evidence arrives. Enter evidence per round (-1 against, 0 neutral, +1 for). The walkthrough applies one round at a time and logs every step until one candidate is committed.

BUILDER'S DESIGN. The source states the collapse idea, not the update rule. This lab's rule: weight w_i becomes w_i x (1 + 0.5 x evidence_i), then all weights renormalize to sum 1. A live candidate whose weight falls below 0.12 collapses out. Candidate names below (Expand scope, Narrow scope, Defer decision, Ask for evidence) are generic builder placeholders, not QECA doctrine.

5. Tool 3: HKRS / HASI calculator

Stated (Collision - HKRS; HKRS dossier CORE-008): the Human-AI Synergy Index is a function of Creativity, Adaptability, Expertise, Vision, with Difficulty and Scalability multipliers. The source states the inputs, not the arithmetic.

BUILDER'S DESIGN. This lab's arithmetic: HASI = mean(Creativity, Adaptability, Expertise, Vision) x Difficulty x Scalability. The plain mean is the builder's choice, not a paper formula. A worked case with all 7s and multipliers 1 gives HASI 7. A worked case of 9, 8, 10, 9 with Difficulty 1.5 and Scalability 1.2 gives HASI 16.2. Both are checked in the Node test suite.
