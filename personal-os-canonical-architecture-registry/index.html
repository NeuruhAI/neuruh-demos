1. Scope: what this document is, and what it is not

This document is the canonical architecture and registry spine. It answers three questions: what the architecture is, what each registry records, and where each thing lives. For each entry it gives what it is, what it does or records, where it lives (live URL or local path), and its state on the ladder.

Dedup, by design. Frameworks are covered elsewhere and are not repeated here. What each framework does lives in doc 7, Frameworks: Neuruh Master. Who the agents are lives in doc 10, AI Agents: Neuruh Master. This document covers the architecture and the registry itself, and cross-links both. Where a framework or an agent is named here, it is named only as a node in the architecture or a row in a registry, with the detail left to those two documents.

What counts as the registry spine. The NRH Registry (addressing), the Neuruh IP Registry (Notion), the Dev Log Master Project Registry (Notion), the Atomic Node Registry, the Master Organ and Capability Registry, the N-Cell capability registry, and the Master Map that renders all of them together. Section 9 lists the smaller registries in one line each so they are findable without being duplicated.
