4. Grounding and limits

  • Every row on this page comes from state.json. An empty queue, an empty receipt chain, or an empty git log is shown as empty, never filled with invented rows.
  • Chain status in section 1 is what build_state.py computed by recomputing hashes in Python. The Verify button recomputes the same chain independently in this page.
  • Promotion status is derived from the packet status in the queue: MERGED shows the recorded commit hash, FLAGGED shows the recorded reasons, QUEUED shows the packet is still waiting. A MERGED packet with no recorded commit hash says so plainly.
  • This page makes no network calls except fetching state.json from the same directory. It cannot submit, review, merge, or roll back anything. Those actions run in the Python pipeline, not here.
  • Boundary: real local git repo on this machine only. Not a hosted service, not multi-user, no GitHub remote sync.
