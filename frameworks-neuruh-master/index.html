Section 1

How to read this document

This is a master document, not a pitch. Its job is to state, for each framework, what is known, where the evidence lives, and what is still missing. A framework is covered by four questions, in the same order, every time.

What it is
The definition as the source states it. If the source is a one-line name only, the entry says so.
What it does
The function as the source states it. If no function is stated anywhere in the sources read, the entry says UNKNOWN, not a guess.
Where it lives
A live URL, a local path, a repo name, or a named document. If none exists on record, the entry says so.
State
One rung on the ladder below, as of the audit date 2026-11-18.

State ladder

StateMeaning in this document
CONCEPTNamed idea only, no design written.
DESIGNEDA design, paper, or specification exists. No running code is evidenced.
IMPLEMENTEDCode or a working local build exists. Not deployed as a service, not live.
TESTEDCode exists and a test suite or check has been run against it, with the result on record.
LIVEReachable at a live URL or running on a schedule. A browser-only page is marked LIVE (simulation).
PROVENLive operation demonstrated with receipts. Only one historical run in this document reaches PROVEN, and it is historical, not current.
COMMERCIALTaking money. Zero entries in this document reach COMMERCIAL.
BLOCKEDKnown, named blocker stops it. The reason and what would unblock it are stated.
UNKNOWNNo source read for this document states a function or a state. Named only.

Rules applied throughout: implemented is not deployed is not live is not proven. A simulation is labeled a simulation. SWARM 5,150 is a historical logical-agent design target across 7 legions, never 5,150 live sessions. Full continuous autonomous production execution has not been proven anywhere in the estate; the honest framing is governed, supervised execution with receipts.
