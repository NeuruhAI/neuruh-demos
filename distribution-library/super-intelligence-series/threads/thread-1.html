Thread 1: Anatomy Is Dead (@NeuruhAI voice, 10 posts)

Distills essay-1. Char counts verified per post (all under 280).

1. In 2025 I wrote that obsessing over AI parameter counts would be a relic by 2026. I checked my own homework on Sept 30. It held. Here's what replaced the model: [160 chars]

2. For two years the industry's biggest question was 'which model is biggest.' That question is dead. The top models converged. The gap between #1 and #5 is now smaller than the gap between good architecture and bad architecture on the same model. [244 chars]

3. The physics, plain: an AI remembers what it already read. If two prompts start identically, it skips re-reading the shared part. Change the beginning and it re-reads everything. A timestamp header in your prompt breaks this on every single turn. [245 chars]

4. Same conversation, same model, same answers. I've seen it cost 20x more in input compute purely from prompt ordering (audit 2026-09-30). The expensive part was never the model. It was the order of the words. [207 chars]

5. The fix is three layers. Stable instructions first, never changed. History in the middle, append-only, never rewritten. Volatile stuff last. Cost per completed task stays flat instead of climbing every turn. [207 chars]

6. Quick audit you can run this week: take ten consecutive turns from a real run and diff the prompts. If the first difference is in the first 10% of tokens, you have a prefix problem. Fix that before touching anything else. [221 chars]

7. Admission: my 2025 essay underplayed retrieval. Half the waste in production systems is ungoverned document injection. Full docs where passages would do, retrieved once, never expired. Audit that too. [200 chars]

8. 'Context engineering' is a real job title now. In 2025 I argued the discipline should exist. Now it's table stakes. The edge moved up a level: memory architecture across runs, and how systems degrade over long horizons. [219 chars]

9. I called the end of prompt engineering in April 2025. In 2026 I built what replaced it: chain-of-agent architecture with a never-auto-execute rule, committed Sept 21. Predictions are cheap. Build orders are not. [211 chars]

10. Models are engines. Engines commoditize. The margin moved to the layer above: memory, retrieval, validation. Book 1 of my series is the full manual. Stop picking the biggest model. Start building the architecture. [213 chars]
