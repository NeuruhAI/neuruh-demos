DNA Relationship Probability Calculator

Enter the shared centimorgans (cM) between two DNA matches. The calculator returns every relationship range from the source table that contains that value, plus the probability formula the source defines.

Probability formula (from the source)

P(relationship R | shared cM = X) = (frequency of X cM in relationship R) / (sum of frequencies of X cM across all relationships)

Exact probabilities need Shared cM Project frequency data. That data is not in the source document, so this demo reports the matching ranges only and does not compute a probability. Any probability shown by another tool without that frequency table is an estimate, not a result of this formula.

How to read the result

Ranges overlap on purpose: the same shared cM value appears in more than one relationship band. A match is a candidate, not a verdict. Confirm with known pedigree, age, and additional matches before concluding a relationship.
