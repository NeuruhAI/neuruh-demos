1. How to read this document

The state ladder used throughout is: CONCEPT, DESIGNED, IMPLEMENTED, TESTED, DEPLOYED, LIVE, PROVEN, COMMERCIAL, BLOCKED, STALE, UNKNOWN. DESIGNED is not DEPLOYED, DEPLOYED is not LIVE, LIVE is not PROVEN. A browser simulation is labeled as a simulation. A draft is a draft. A prediction is a prediction, not a measurement. Every public number in this document carries the audit date 2026-11-18.
