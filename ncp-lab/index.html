3. Structure view (stated components only)

NCP Phase 1 pipeline (stated)

Task -> Convergence Router -> Shortcut Edge Layer lookup (learned shortcuts first) -> Semantic Cache Vault (98 percent bypass claimed) -> AtomicNode (1,890 stated; 24 in this demo model) -> Route logged to KuzuDB graph (JSONL fallback) -> Heat Field (heat accumulates per route) -> RAM-disk pin at heat 3.0 (simulated /dev/shm) -> Bloom to organ candidate at heat 6.0, breadth bar applies -> Repeat (route, log, heat, mint, bloom, repeat)

The pipeline order follows the stated loop and the lattice transcript. The "mint" step (minting a shortcut from repeated routes) is represented in this demo by the Shortcut Edge Layer remembering each task once routed.

6. Receipt panel (receipt format v1.0)

Every router run and every calculator run emits a receipt. Receipts chain: the first receipt in a session has prev_hash GENESIS, and each later receipt chains to the previous receipt's hash. The hash covers the canonical JSON of the receipt with the hash field stripped, using SHA-256.

No receipts yet. Route a task or run the calculator.

Verification runs in this browser with the Web Crypto API and recomputes every hash from the stored receipt text. A changed receipt or a broken chain link reports FAIL.

9. Lab design decisions (mine, labeled)

  • 24-node model lattice instead of the stated 1,890 nodes, so the whole lattice is visible and testable.
  • FNV-1a hash of the normalized task text, mod 24, picks the node. Deterministic and shown step by step.
  • Heat rises 1.0 per route. Pin at 3.0 and organ at 6.0 use the stated thresholds; the breadth bar is set at 2 distinct tasks (unstated number, my choice).
  • Conditional shortcuts fire on the two exact condition phrases stated in the lattice transcript, case-insensitive.
  • The bypass calculator reports calls avoided and calls to the LLM only. No money figures appear anywhere on this page.
  • Receipts follow the receipt format v1.0 pattern used by the other labs: canonical JSON, hash stripped, SHA-256, GENESIS first, chained.
