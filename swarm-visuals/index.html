03 — The Unit of Speech

Every message is an evidence packet

Free-form agent-to-agent text is disallowed — it would bypass the evidence invariant. If a packet lacks sources or a falsifier, the Fusion Gate refuses it.

"packet": {
  "claim": "Delaying the vendor payment
           by 9 days keeps cash above floor.",
  "confidence": 0.82,
  "supporting_capsules": [
    "cap_contract_terms_v3",
    "cap_cash_position_oct17",
    "cap_prior_delay_outcome"
  ],
  "falsifiers": [
    "A receivable slips past Oct 24",
    "Vendor invokes late-fee clause §4.2"
  ],
  "heuristic": "preserve-floor-first",
  "heuristic_calibration": 0.71 (n=34),
  "trace_id": "tr_8f31…",
  "timestamp": "2026-10-18T11:42Z"
}
Claim + confidence

One checkable assertion, never a paragraph of vibes. Confidence is calibrated against later outcomes, not self-reported flair.

Supporting capsules

Pointers into the mesh. Minimum coverage is enforced by code — below the floor, no positive claim is emitted; the gap is shown instead.

Falsifiers

What would make this wrong. The single most useful field in the packet, and the one unconstrained agents never produce.

Trace + lineage

Every packet is logged immutably. Rejected packets become synthetic stress cases replayed nightly.

05 — The Experiment

Four systems. One mesh. 4–6 weeks.

Small enough to instrument completely, large enough to prove whether reliability + compounding actually beat unconstrained agents.

SYSTEM 01

Evidence-Gated Operator

A single-domain founder/ops agent that only emits a recommendation when it can attach grounding — and never executes an irreversible action itself.

  • Router: cheap model for summaries, strong model for multi-hop
  • Semantic-Fuse-style blocker under confidence / source floor
  • Human checkpoint before any send, schedule change, or spend
Measure: acceptance rate · edit distance · source coverage · outcome match vs. unconstrained baseline, 30 days
SYSTEM 02

Capsule Cascade Memory

The knowledge base that sharpens with use. Atomic capsules, automatic links, context injection, cascade updates, noise filter.

  • Correction to one capsule flags dependents for re-evaluation
  • Low-utility nodes archived, never silently deleted
  • Exportable “capsule packs” carry provenance with them
Measure: retrieval precision · time-to-answer on repeats · contradiction detection rate over 4 weeks
SYSTEM 03

Heuristic Extractor + Outcome Loop

Mentors become procedures, not pastiche. Each heuristic is a falsifiable rule with applicability conditions and a live calibration score.

  • Extract from source material + your own past decisions
  • Backtest on decisions whose outcomes are already known
  • Low-calibration heuristics demoted automatically
Measure: calibration · outcome delta vs. unguided decisions · revision rate
SYSTEM 04

Stack Constructor

A factory that turns any new narrow task into a guarded, measurable stack using the AI Stack Blueprint: logic → execution → output → feedback.

  • Standard guardrails instantiated: spend, scope, PII, checkpoints
  • Dashboard: success rate, source coverage, edit rate, cost / win
  • Its own design proposals must arrive as evidence packets
Measure: time-to-first-working-stack · 1-week stability · do metrics surface problems faster than ad-hoc builds?
06 — 10× Without Sacrifice

Compound the evidence, not the risk

The invariants never relax. Speed comes from propagating confirmed evidence faster and fusing independent traces before a human ever sees the result.

×1

Cascade amplification

One confirmed correction re-scores dozens of dependent capsules and proposes new links. A small proposer model suggests; nothing commits without grounding.

Track: downstream citation rate
×2

Parallel traces + fusion

3–5 independent traces per hard question. A claim survives only if ≥2 traces agree on overlapping sources. Disagreement is surfaced, never averaged away.

Track: fusion acceptance rate
×3

Outcome-conditioned promotion

Heuristics harden into default logic only after measured outcomes cross threshold + sample size. Demotion is automatic and reversible.

Track: calibration trajectory
×4

Synthetic stress packets

Every rejection, heavy edit, and outcome miss becomes a test case, replayed nightly. Regressions block promotion of any stack change.

Track: replay pass rate
×5

Externalization flywheel + shadow

High-calibration packs export to other teams / verticals and return new outcome data. Shadow Simulator attaches consequence sketches — evidence, never orders.

Track: shadow accuracy
Watchdog kills the trace

Timeout, schema violation, or budget breach: trace dies, event logs, retry on a different Reasoner or return “insufficient evidence.”

Conflict is a first-class output

Two high-confidence packets disagree? Both capsule sets are shown side by side. No automatic averaging, no coin flip.

Cost spike = degrade gracefully

Router shifts work to cheaper models and cuts parallel traces. Governance Plane can hard-cap spend mid-flight.

07 — The Filter

What survived 15 months

Sources dated June–July 2025, re-read October 2026. The test applied throughout: can it be proven, built, and measured right now?

✓ Kept — build from this

  • Reliability primitives: Semantic Fuse, Hallucination Debouncer, Impedance Matcher / router, Context Buffer, watchdog timeouts
  • Governance: packets, deterministic policy gate, receipts, human-in-the-loop on irreversible actions
  • Self-Compounding Knowledge Engine: capsules, link matrix, context injection, update cascade, signal-to-noise filter
  • AI Stack Blueprint: logic, guardrails, embedded knowledge, modular build, metrics, versioning
  • Awareness → Automation → Augmentation → Transformation, applied to one domain at a time

✕ Discarded / parked

  • Quantum equations claiming 4–6× from 20-qubit, 2023-era parameters — functional forms force the result; no reproducible benchmark supports them
  • Exhaustive 15-domain micro-agent catalogs before the core is measured
  • Pure stylistic mentor emulation without extracted, calibrated heuristics
  • Near-term BCI and full embodiment as product claims — horizon research only
  • Peer-to-peer AV pod concept — interesting, orthogonal, separate bet
Non-bypassable gates

Source minimums, confidence floor, PII scrub, spend ceiling, scope boundary — deterministic code, not model judgment.

Single source of state

The mesh. Agents propose updates; only confirmed outcomes or human edits commit them. Capsules are versioned, never mutated.

Measured continuously

Source coverage · fusion rate · edit distance · outcome match · cascade citations · cost per grounded output · watchdog interventions.
