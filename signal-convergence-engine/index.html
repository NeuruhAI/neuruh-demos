Signal Convergence Engine

Browser implementation of the source pipeline: ingest, n-gram motif mining, metaphor detection, DIMEA cross-link, mirror vocabulary matrix. Simulation of the specified Python pipeline, not the pipeline itself.

Browser simulation

Source: Google Doc "SIGNAL CONVERGENCE ENGINE - FULL STACK BUILD", Drive 2025-07-13. The Python pipeline in the source has never been shown running, and reading it found four defects. They are fixed here and listed below. The JS version tokenizes and lemmatizes lightly (lowercase plus a small stem rule) instead of the 500 MB spaCy model. No text leaves the browser.

Defects fixed vs the source: (1) ngram_miner.py loads engine.toml with yaml.safe_load, but TOML key = value lines are not valid YAML, so it fails. Fixed: config is parsed as TOML-style key/value here. (2) build_matrix.py iterates motifs.json top-level keys, but the miner writes {"motifs": {...}}, so it reads the wrong level. Fixed: the motif dict is read from the "motifs" key. (3) metaphor_sniffer.py returns bare regex fragments ("like a") instead of sentences. Fixed: the containing sentence plus the matched pattern is returned. (4) requirements.txt pins pandas==3.0.0, a release that does not exist on the public index. Not applicable in JS; flagged for the Python run. Also: context_window = 5 is configured but never used by any module (dead config), and Node.js is listed as a prerequisite although nothing uses it.
