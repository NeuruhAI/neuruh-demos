Formulas used

  • SHA-256, toUtf8, hashStr, and canonical JSON copied verbatim from ~/workspace/unified-chain/unified-chain.js (lines 17-86).
  • Receipt canonical v1.1: receipt_hash is SHA-256 of canonical JSON (sorted keys, arrays in order) with receipt_hash and receipt_id removed. receipt_id equals receipt_hash. First prev hash is the literal string GENESIS. Fields: action, actor, timestamp, payload, prev_receipt_hash, merkle_root, anchor_root. merkle_root is the chain head hash the receipt builds on (GENESIS for the first receipt); the new head after sealing is receipt_hash. anchor_root is the estate Anchor v2 root afd56cea3e4abe9265f83c3552cddebac2771ab6d5d50012a641695fd8b8777f.
  • Eta: eta = (I_q I_r I_v) / (1 + E_wasted + C_violations), clamped to 0-100, threshold 70. CRUCIBLE PASS only when eta is at or above 70 AND uncited count is zero, else FLAG naming the exact claims to fix.
  • N-Cell/64 header: 8 bytes in unified-chain stage 2 order (routeMask, organMask, lifecycleMask, authorityMask, memoryMask, confidence, risk, outputMask). Route is a deterministic hash of the author agent string, confidence is eta scaled to 0-255, risk is blast-radius words in the diff scaled to 0-255.
  • Seven agents (Hawkins Correctness, Orwell Security, Keystone Test Coverage, Advocate Blast Radius, Cicero Style/Consistency, Zeitgeist Documentation, Empath Risk) are deterministic rules over packet fields, in isolation. Confidence is seeded by a deterministic hash of packet text plus lens name, 0.50-0.99. Chair aggregates by confidence-weighted majority verdict.
  • Promotion gate PASS only when eta is at or above 70, uncited count is zero, and authority is valid (scope non-empty AND token non-empty AND expiry date in the future).

Eta prefill discrepancy, recorded honestly

The brief said the prefill (I_q 88, I_r 90, I_v 85, E_wasted 1, C_violations 0) gives eta about 78. It does not under the stated formula. The literal formula gives raw (88 90 85) / (1 + 1 + 0) = 336600, which clamps to 100. The page shows the computed value, raw and capped, and states this discrepancy in its Grounding section. It does not repeat 78 as a result. The verdict is PASS either way (100 is above 70).
