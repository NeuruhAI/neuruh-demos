01The ruling: the endgame

The Execution Topology Canon states the ruling plainly. The estate already contains the machinery required for autonomous execution. The failure mode is not missing architecture. It is broken continuity between existing control surfaces plus excessive re-census and re-audit work. The operating correction is: do not rebuild the organism, restore the event-driven execution path.

The canonical directive from the same page is the endgame in one line: converge, restore event-driven autonomy, push proven candidates to remote custody, close DeedSonar, get a real economic outcome. Then four refusals. No more architecture expansion as a substitute for closure. No more full-machine archaeology as a default. No more making Jeramie carry state between agents. No more successful local candidate dying because the model session ended. No more claiming shipped without Git, provider, and runtime proof.

Convergence Delta 01 names the dominant failure mode the same way: lineage fragmentation, semantic collision, under-wiring, and ambiguous ownership, not absence of architecture. The R14B anti-loss work preserved about 225 named lineages. The plan therefore binds and restores. It does not invent a new organism.

04Phase 1: Acceptance, what working means

NEXT Sources: Chapter 12, Runtime Acceptance Topology (last edited September 6, 2026).

What gets built. The acceptance surface as running code. A live probe that reads the 24-node manifest and the 17-plus-1 SOPS court and reports each node's true state with evidence. The lifecycle semantics from Chapter 12 are enforced, not described: ACTIVE, READY_ON_DEMAND, OPTIONAL, RETIRED, ABSORBED, BUILT_NOT_WIRED, DEGRADED, and UNVERIFIED. The live-state rule from the same chapter is the probe's contract: expected source and pin identity, expected process and port owner, semantic health and not merely HTTP 200, current receipt and ledger freshness. The 24-node manifest and the 17-plus-1 SOPS court answer different questions on purpose: a manifest describes intended topology, SOPS describes the supervised acceptance surface, and a live court says what is actually serving now. The probe keeps them separate. The known lineage decisions carry forward: Territory is RETIRED, SAL is ABSORBED into AXON and governance and feedback components, OMNIA-6 is ABSORBED into the AXON PromptComposer path, the PMLA live execution gate is ABSORBED into the AXON PmlaGate, Synapse Router is RETIRED, PulseBus is ABSORBED into receipt ledgers and observation ingest, LandOS and Recipe Engine are READY_ON_DEMAND.

Proof. The probe runs on the new substrate and returns a state digest per node: state, observed_at, source, source SHA, reason, authority, digest, and staleness. A node with no observation reports UNVERIFIED, never ready. A deliberately stopped node reports RETIRED or ABSORBED, never down. A node that answers HTTP 200 but fails its semantic contract reports DEGRADED. No false ready, anywhere, ever.

Receipt integrity rules are enforced at every step: mission and correlation identity, source SHA and tree and fingerprint, authority reference, idempotency key, timestamp, evidence references, content hash and sealed identity, explicit state transition, and explicit failure or refusal when unavailable. Proof. One full chain executed end to end with sealed receipts at each step and an independent Sentinel verdict that the builder did not write. 11The loop: the organism, one loop, twelve layers

Chapter 02 states the thesis: the architecture did not repeatedly restart. The vocabulary changed as the same organism grew from a five-layer model, to three operating altitudes, to the modern JGI execution fabric. The stable DNA, distilled from the July estate inventory, is one repeating pattern: signals in, structured and scored decision, receipt out, outcome feedback. It runs at three altitudes: money (signals, parcels, businesses to decisions to CRM, deal, revenue), knowledge (files, pages, conversations to audit to canon and training corpus), and compute (tasks to model and tool routing to execution to hash-chained receipts). Governance wraps every altitude.

The twelve layers are the loop the runtime runs: L0 Founder Intent (objective, constraints, consequential approvals), L1 Mission Compiler (mission id, measurable outcome, DAG, evidence, authority, rollback, budget, stop conditions), L2 Estate Truth and Canon (Git, local, runtime, Notion, receipt, and provider census with evidence classification), L3 Scheduler and Workflow (persistent jobs, deterministic ids, idempotency, crash resume, retry and deadletter), L4 Event Fabric (typed state transitions, no founder copy and paste transport), L5 Authority and Governance (action permissions), L6 Capability Membrane (exact tool, repo, path, network, and privilege bounds), L7 Specialist Swarms (narrow workers and mission pods), L8 Verification Court (independent Sentinel, builder never closes itself), L9 Git Custody and Promotion (exact independently-passed candidate to feature branch to PR to CI), L10 Runtime and Deployment (exact SHA, canary, rollback, semantic probes, runtime receipts), L11 Telemetry, Learning, and Revenue (outcomes, cost, latency, calibration, economic feedback).

The body map names the parts so the phases can be checked against it: brain and inference is IAR plus Aegis plus model substrate; nervous and event system is AXON, Switchboard, and Workers; immune system is Governance, constraints, drift, Semantic Fuse, and Sentinel; memory is Vault, receipts, outcome stores, and Notion projection; hands are bounded workers and capabilities; eyes are telemetry and provider courts; face is Cockpit, DeedSonar, and public surfaces; heartbeats are scheduler, watchdog, and runtime supervision; blood is events, receipts, and state transitions.
