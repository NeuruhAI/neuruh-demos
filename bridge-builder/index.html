The Bridge Builder

Fill in a case and generate a bridge page with the same structure as the Reitz–Blumenthal bridge: correction banner, cast, timeline, statutes, the allegation map with a perspective toggle, a computed honest tally, the "what would have to be proven" checklists, counter-arguments, and sources. The form is preloaded with the Reitz–Blumenthal case so you can see it working immediately, then change any field and generate a new bridge.

Honesty rules, baked in

Allegations are allegations. Every claim on a generated bridge is labeled ALLEGED, CONTESTED, NOT ESTABLISHED, or ESTABLISHED, and attributed to its source. No one is declared guilty. The tally is computed from the element statuses you set in §9, never hardcoded.

The generator refuses to build a bridge with no allegation and no sources. If the allegation map is empty or the source list is empty, generation stops and the error tells you what is missing.

ESTABLISHED is a high bar. If you mark an element ESTABLISHED without any evidence or source, the generator warns you before it builds. An element is established only when the public record proves it, not when a side asserts it.

The labeling is fixed. Every generated bridge carries: "ALLEGATION MAP, not a finding. No one has been charged. No court has ruled." unless you supply verified charges or rulings in §1, in which case the scoreboard shows them and the labeling updates to match.

1. The case

2. Correction banner

Use this when the viral or popular version of the story is wrong. If there is no misattribution to correct, use it for the most important procedural fact instead (for example, that a letter went online before the recipient received it). Leave the title blank to omit the banner.

3. The cast

One row per actor. Name plus a short description of who they are and what they did in this case.

4. Timeline

One row per event, in date order. Date can be a single day or a range.

5. The statutes

Usually two. For each: the code, the name, the tag shown next to the heading, whether it is a conspiracy statute, the quoted language, the elements (one per line), the penalties (one per line, as "Outcome | Maximum penalty"), and a note.

6. The distinction, stated plainly

The paragraph or paragraphs that explain how the statutes differ and what neither one criminalizes. One paragraph per line.

7. The two directions

8. The bridge: allegation → law → actor

One row per alleged act. Direction A is the first side's allegation; Direction B is the counter-allegation. Status means: ALLEGED (the act or fact is documented but the legal conclusion is not drawn), CONTESTED (both sides have stated a position and the public record does not resolve it), NOT ESTABLISHED (no evidence for that element has been produced publicly), ESTABLISHED (the public record proves it; needs a source).

9. What would have to be proven

One row per statute element, per statute. Give each element a status for Direction A and a status for Direction B. The honest tally is computed from these two columns: ESTABLISHED counts toward the tally, everything else does not. The scoreboard shows the first statute's tallies; the tally note in §5 of the generated page lists every statute.

10. Counter-arguments and defenses

One card per argument. Give each a title and its body text.

11. Sources

At least one source is required. Give the citation text and the URL. If a source has no URL (for example, a letter image circulating on social media), leave the URL blank and say so in the text.
