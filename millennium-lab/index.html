01What the lab is

The atlas stated the six problems and named six computable first moves. The lab is where those moves get executed. Each move is a real program with a real run, a real result file, and a hash-chained receipt, so anyone can re-run it and check it. Two moves ran on November 20, 2026. Four are named, scoped, and not yet run. The lab grows one move at a time, and a move counts only when its receipts exist.

The receipt chain is the sovereign runtime receipt format, direct reuse: the production SovereignStore class from ~/workspace/sovereign-runtime, canonical JSON, SHA-256, each receipt carrying the hash of the previous one, GENESIS head. The lab ledger is a separate store (data/lab.db) in the same format. The chain was verified after the store was closed and reopened, which is the restart proof. 02Riemann: first 1,000 zeros, re-verified

RUN November 20, 2026. Method: PARI/GP 2.19.1 lfunzeros locates every zero with imaginary part in [0, 1420] (C implementation, Riemann-Siegel, argument principle). Then, for each located t, an independent mpmath Newton step from 0.5 + i t using zeta and zeta prime, at 30 decimal digits. The Newton step is free to move off the line; the reported real part is where it converges. The two implementations agree: the first zero from PARI matches the mpmath bisection value to 22 digits.

Result: 1000 zeros checked, first at t = 14.13472514173469379045725, last at t = 1419.422480945995686465989. Largest deviation of a zero real part from 1/2: 0.0 at 30-digit precision (no zero deviated: every Newton step returned Re = 1/2 exactly at this precision, so the deviation is below 1e-30). Largest |zeta(1/2 + i t)| at a located zero: 5.6087e-26. Count check against the Riemann-von Mangoldt formula at T: expected 999.42 zeros, found 1,000, so S(T) = 0.582, inside the small range the formula allows. PARI location scan took 44.46 seconds; the mpmath verification pass took 88.73 seconds.

This is a re-verification, not a new record. The first 1013 zeros were already verified on the line by others. This run checks the first 1,000 again, independently, on this machine, with receipts.

03Birch and Swinnerton-Dyer: one curve family, computed

RUN November 20, 2026. Family: every elliptic curve over Q of conductor at most 20, as enumerated by PARI ellsearch. That is 28 curves in six isogeny classes (conductors 11, 14, 15, 17, 19, 20). There are no curves of conductor 16, and none of conductor 12, 13, or 18. Method: PARI/GP 2.19.1, built from source on this machine, ellanalyticrank at 30 digits of precision. The conductor of every curve was recomputed here with ellglobalred and matches its label. Rank method: analytic rank, the order of vanishing of L(E, s) at s = 1.

Result: every curve has analytic rank 0, and every L(E, 1) is nonzero. That is exactly what Birch and Swinnerton-Dyer predicts for rank 0 curves: rank 0 if and only if L(E, 1) is nonzero. L-values repeat within an isogeny class, because isogenous curves share an L-function. Torsion orders range from 1 to 8. The smallest conductor carrying a rank 1 curve is 37, which is outside this family, so a rank 0 outcome across the family is the expected result, and the run confirms it rather than discovering it.

06How to re-run

Everything is in ~/workspace/millennium-lab/. Riemann: ./pari/bin/gp -q < compute/riemann_scan.gp > data/riemann_t.txt (PARI/GP 2.19.1, built from source, installed under pari/ in this folder), then python3 compute/riemann_verify.py (mpmath 1.2.1, system Python 3.12.3). BSD: ./pari/bin/gp -q < compute/bsd_curves.gp, then python3 compute/bsd_curves.py. Receipts: ~/workspace/sovereign-runtime/.venv/bin/python compute/receipts.py (uses the production SovereignStore class; writes data/lab.db and data/receipts.json). Page: python3 compute/build_page.py. The earlier pure-mpmath scan scripts (riemann_zeros.py, riemann_zeros_v2.py) are kept in compute/ as the record of the slow path: the mpmath Z-function scan costs about 10 ms per evaluation at 30 digits in pure Python, which made 108,400 evaluations too slow, so location moved to PARI and mpmath kept only the independent real-part check.
