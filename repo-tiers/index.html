How to read the tiers

Tier 0 is live or deployed today. Tier 1 is real and sellable now. Tier 2 is one fix from sellable, and the verdict names the fix. Tier 3 should be retired or folded into a stronger repo. Tier X carries a claim the code does not support, so it is reputational risk until reclassified. Tier S is a README-only shell to archive.
