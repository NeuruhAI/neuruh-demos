Sourcing and omissions

  • Rows shown: 246. Rows sourced from the census file (Master-Data-List.json): 246, all labeled CENSUS. Rows omitted: 0.
  • 231 rows carry the R14B six-source census source type (2026-09-05) plus the GitHub/Notion/Drive lanes (2026-11-08). The other 15 rows were seeded later by census-gap recoveries and court-pass fixes; each row's detail view shows its own source type.
  • Every vault path was checked against the vault on disk at build time; all 246 resolve to a note file.
  • Collision notes: 15 exist in 00-Collisions/, all with court verdicts recorded 2026-11-09. 11 map to census concepts and are flagged COLLISION in the table. 4 collision names (A.G.E.N.T., L4, Pulsar, ReAuditor) have no census row; they are named here only and are not shown as concepts, because no concept row exists for them.
  • No tier field exists in the census data. The census records a final classification, a runtime, and an owner per concept, but no A/B/C/GATE tier. No tier filter is offered and no tier was assigned, because inventing one would falsify the record.
  • Runtime filter rule: "Repo evidenced" means the census runtime string contains REPO EXISTS; "No repo" means it is exactly NO REPO; "Unknown" means exactly UNKNOWN; anything else is "Other / described" and shown verbatim in the detail view.
