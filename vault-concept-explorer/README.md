# Vault Concept Explorer (SIMULATION)

A searchable, filterable browser over the 246 census concepts in the Neuruh
Obsidian vault. Static page, no backend. Live at
https://neuruhai.github.io/neuruh-demos/vault-concept-explorer/

## What it does

- Text search across concept names, aliases, IDs, sections, classifications,
  runtimes, owners, and vault paths.
- Filter by section (10 vault sections), by classification (substring match
  against the census final classification, 176 distinct values, datalist
  supplied), by runtime bucket, and collision-notes-only (11 rows).
- Sort by name A-Z / Z-A or ID ascending / descending.
- Click a row for a detail view: tier-free detail showing section,
  classification, runtime, owner, aliases, vault source file, evidence
  standard (source type), source references, recorded conflicts, collision
  status, and row sourcing.

## Data

- `concepts.json`: 246 rows, generated by `build-data.py` from
  `~/workspace/neuruh-obsidian-vault/Master-Data-List.json`. Every row is
  labeled `CENSUS`. 0 rows omitted, 0 rows invented.
- Vault paths are derived with the vault generator's own slug rule
  (`build_vault.py` slug: "/" becomes " - ") and were all verified to exist
  on disk at build time (246 of 246).
- 231 rows carry the R14B six-source census source type; the other 15 were
  seeded later by census-gap recoveries and court-pass fixes. Each row's
  detail view shows its own source type.
- Collision flags come from the 15 collision-note names on the Vault
  Overview page (2026-11-14). 11 map to census concepts. The other 4
  (A.G.E.N.T., L4, Pulsar, ReAuditor) have no census row and are named in
  the page footer only, not shown as concepts.

## No tier field

The census records a final classification, a runtime, and an owner per
concept, but no A/B/C/GATE tier. No tier filter is offered and no tier was
assigned. The page states this in its footer.

## Runtime bucket rule

Stated on the page: "Repo evidenced" means the census runtime string
contains REPO EXISTS (61 rows: 60 exact plus CORE-059 "REPO EXISTS (NOT
DEPLOYED)"); "No repo" means exactly NO REPO (167); "Unknown" means
exactly UNKNOWN (4); anything else is "Other / described" (14) and shown
verbatim in the detail view.

## Tests

`node test.js` runs 20 headless tests against the same `explorer.js` the
browser page loads and the real `concepts.json`. No dependencies, Node 24.
As of 2026-11-14: 20/20 pass.

## Deploy

`deploy.py` pushes index.html, explorer.js, concepts.json, test.js, and
build-data.py to NeuruhAI/neuruh-demos under `vault-concept-explorer/` via
the GitHub Contents API (GET sha first, PUT, 409 retry with fresh sha, 3s
pause between PUTs, MD5 skip-if-unchanged). Auth via the stored vault
credential, same helper as the other demo deploy scripts. No raw credential
is read, printed, or persisted.
