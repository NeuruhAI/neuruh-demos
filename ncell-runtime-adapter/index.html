N-Cell Runtime Adapter

Header stamper, governance intersection calculator, and topology receipt emitter. A working simulation of the adapter design described in the paper.

Honest label: this is a simulation, not a running adapter

This page simulates what the N-Cell runtime adapter would do if it existed. It does not connect to AXON, to any registry, to any organ, or to the Vault. Every mask bit meaning on this page is a placeholder the user defines here, not a value from any live system.

  • No Organ Manifest exists for any organ. Until a manifest exists, organMask in a real N-Cell header is meaningless (source claim, runtime-scoping.md).
  • No versioned mask schema exists. The paper requires the bit-to-meaning mapping to be declared in a versioned schema. None exists, so this demo uses placeholder mappings labeled as placeholders.
  • No adapter repo, host, API, or store is named in any source. Language, host, and storage for the adapter are UNKNOWN.
  • The paper's verification thresholds are unmet: no 20 percent efficiency gain has been measured, zero silent high-risk execution has not been demonstrated, and no paid or operational outcome with a documented counterfactual exists.
  • The paper's own verdict: the adapter should not be built until a stable runtime exists. This demo shows what the adapter would do; it is not the adapter.

5. Try-it walkthrough

  1. Load Sample A. Press "Sample A: passes governance". The header stamps to 07 07 08 1F 07 CC 33 07 and the intersection equals the proposed set. Press "Emit receipt" and note receipt R-001 links to genesis hash 00000000.
  2. Load Sample B. The planner proposes the world.emit edge, but policy does not allow it. Compute the intersection: world.emit appears under "Blocked by policy" and the verdict drops to PARTIAL. Emit a receipt; its prevHash is R-001's hash.
  3. Load Sample C. Policy allows every proposed edge, but the QCM to N-Lab edge is unavailable (tool down). It appears under "Blocked by infrastructure".
  4. Change one bit. Toggle any route bit and press "Stamp header" again. The header hex changes, and the receipt delta (XOR against the previous header) is shown in the receipt.
  5. Verify the chain. Press "Verify whole chain". Then use "Tamper" on any receipt to see verification fail, and "Restore" to fix it.
  6. Share it. Press "Generate share link", copy the link, open it in a new tab: the same state restores.

6. How it works / What this is not

How it works

  • Header stamper: each mask byte is the sum of 2^i over the checked bits (paper section 3.2). Confidence and risk percents are quantized with round(pct / 100 x 255). The 8 bytes are shown as hex, binary, and decimal.
  • Governance intersection: real set math over the three edge sets. E* = proposed ∧ allowed ∧ available. Blocked by policy = proposed minus allowed. Blocked by infrastructure = (proposed ∧ allowed) minus available.
  • Receipt emitter: each receipt stores the header, the intersection, the verdict, a semantic note, the XOR delta against the previous header, and a hash chain link (FNV-1a over prevHash, header, run, intersection, verdict).
  • Share link: the full state is base64 JSON in the URL hash and restores on load.

What this is not

  • Not a running adapter. There is no AXON connection, no registry, no live organ, no Vault write.
  • Not a mask schema. No versioned schema exists; the bit meanings here are placeholders the user defines.
  • Not a governance decision. Policy and availability sets are typed in by hand; no policy engine evaluates them.
  • Not a receipt store. Receipts live only in this page (and in a share link). The Vault stores real receipts; this page does not touch it.
  • Not evidence for any verification threshold. No benchmark, baseline, ablation, or outcome was measured here.
  • Not peer reviewed or benchmark validated, same as the source paper itself (v0.1, founder working paper).

7. Honest gaps

What the sources do not define, or what could not be verified while building this demo. Gap marks each item.

  • Gap No Organ Manifest exists for any organ. Source claim (runtime-scoping.md): "Until a manifest exists, organMask in an N-Cell header is meaningless" and "no manifests written for any organ". The organ checkboxes here are labels only.
  • Gap No versioned mask schema. The paper requires the bit-to-direction / bit-to-meaning mapping to be declared in a versioned schema. None exists for route, organ, lifecycle, authority, memory, or output masks. All mappings on this page are demo placeholders.
  • Gap No adapter repo, language, host, API, or store named. The paper is language-agnostic and names only "the live AXON/registry stack" as the host. The live state of that host stack is UNKNOWN in the scoping read.
  • Gap Conflicting build guidance in the sources. Paper section 8 lists "build the N-Cell instrumentation adapter on the live AXON/registry stack" as a verification-program step, while FULL_ANALYSIS (via runtime-scoping.md) rules "Do not build the runtime adapter until a stable runtime exists" and "N-Cell is premature for a prompt-based engine". This demo follows the stricter ruling: simulate only, build nothing live.
  • Gap Verification program unmet. No fixed-topology baselines, repeated trials, ablations, failure injection, or cross-domain transfer results exist in the sources. Thresholds (20 percent efficiency gain, zero silent high-risk execution, one paid/operational outcome with documented counterfactual) are all unmet. Hypotheses H1-H8 are stated with no results.
  • Gap Receipt hash is demo-grade. FNV-1a 32-bit is a checksum, not a cryptographic hash chain. A real receipt chain would need a stated hash function and a Vault; neither is specified in the sources.
  • Gap Confidence and risk quantization is assumed. The paper says confidence and risk are 0-255 but does not specify the mapping from a 0-1 score. This demo uses round(pct / 100 x 255); the extraction schema notes a JSON form with 0.00-1.00 floats, which this demo does not use.
  • Gap Layout not eyeballed in a real browser. The page was tested in jsdom only. Visual layout in a real browser is unverified.
