How assembly works

1. Placeholders in the template that match a field name are filled with your value. 2. A changed value replaces its default where the default appears in the template. 3. Anything else you type is listed under ADDED TOKENS, so nothing is dropped. 4. Unfilled placeholders stay visible and are listed as MISSING. Templates are verbatim from the canons, including the canon's own inconsistencies.

Examples Library

How the Examples Library works

Each builder has example prompts you can pull field values from and example outputs you can view or copy. Examples you add live in this browser until you export them, so export the file to keep them. The pool dedups identical entries, so the same text cannot be added twice to one builder. The most-used examples surface first in each list.
