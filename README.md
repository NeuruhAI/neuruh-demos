# Neuruh Demos

Working browser demos of Neuruh systems and documents, hosted on GitHub Pages.

Site: https://neuruhai.github.io/neuruh-demos/

## Demos

| Demo | What it is |
|---|---|
| [maximum-resolution-blueprint](maximum-resolution-blueprint/) | Gap tracker, formal models explorer, build roadmap for the Adaptive Intelligence Maximum-Resolution Expansion Blueprint |
| [swarm-mission-dag](swarm-mission-dag/) | Mission DAG composer, ephemeral worker lease simulator, hash-chained receipts |
| [ncell-runtime-adapter](ncell-runtime-adapter/) | N-Cell/64 header stamper, governance intersection calculator, topology receipts |
| [autonomous-builder-factory](autonomous-builder-factory/) | BuildFix cycle tracker, CODE PACK queue, asset registry |
| [opportunity-genome](opportunity-genome/) | Genome composer, version diff, cross-domain mapping |
| [component-library-gallery](component-library-gallery/) | 25 .tsx components re-implemented as live working components |

Each demo is a single self-contained HTML file (inline CSS/JS only, no external dependencies, no external fetches). Each was verified with jsdom tests against hand-computed values, 0 failures.

## Honest labeling

These demos are browser simulations of designs and documents, not live production systems. The SWARM demo is an architecture candidate, not a live runtime. The N-Cell adapter demo simulates an adapter that has not been built (no Organ Manifest exists). The Autonomous Builder demo simulates a control plane whose registry must be fixed before it is real. The Opportunity Genome demo proposes a schema; it is not canonical. Each demo page states what it is and what it is not.
