How it works / What this is not

How it works

  • All three datasets live in this single file as plain data. Every rollup and count is computed from that data when the page loads and after every change.
  • BuildFix cycles: 64 rows with a fixed date and status split, filterable by status and date.
  • CODE PACK queue: 100 rows in the Draft to Posted state machine, with one-step Advance transitions.
  • Asset registry: 103 rows, split 58 Notion artifact and 45 code pack, with a simulated test, push, and deploy ladder.
  • Share links encode the four filters as base64 JSON in the URL hash and restore them on load.

What this is not

  • Not a running factory. No code is built, tested, pushed, or deployed by this page.
  • Not connected to Notion. There is no Notion control plane behind this page, no live queue, and no heartbeat tick.
  • Not the recorded factory path. ~/repos/autonomous-builder/ does not exist on this machine.
  • Not a verified registry. The 103 "Built" labels come from the audit claim, and the audit itself says Built means Notion artifact or code pack only.
  • Not a verdict on the April program. The April cycles are a historical record; this page simulates their control plane so the gap is visible.

Honest gaps: what the sources do not define or what could not be verified

  • Factory repo and runtime: unknown. No builder code, repo, language, host, or deploy target was found in either source. The only path on record is ~/repos/autonomous-builder/, which does not exist on this machine. GitHub state was not checked in this build.
  • Whether any of the 103 assets was ever tested, pushed, or deployed: unknown. The audit defines Built as Notion artifact or code pack and reports zero further evidence. This demo starts all three later states at zero because the audit gives no other number.
  • 60+ cycles vs 227-row corpus: unreconciled. The sources give "60+ BuildFix cycles Apr 17-20" and separately a 227-row corpus (178 Success, 47 No-op, 1 Queued, 1 Running) from a 2026-09-14 dossier appendix. The two counts are not the same set, and no source maps one onto the other. This demo uses 64 cycles for the tracker and reports the 227-row corpus only as a separate lineage record.
  • ~100 CODE PACKs vs 103 assets: overlap unclear. The sources say about 100 CODE PACKs were filed and separately that 103 Autonomous Builder assets exist. Whether the packs are a subset of the assets, the same set, or a different set is not stated. This demo keeps them as two separate tables and does not merge them.
  • n8n contract and heartbeat: current state unknown. The sources name an n8n contract spec for the Publishing Queue and 15-minute AXON Gateway heartbeat ticks. Whether either still runs, and what the current Build Queue depth is, is unknown.
  • Codex V3 audit numbers are IP-wide, not asset-only. The 1,181 IP records, 691 Built, 630 lacking Layer, 1,003 lacking folder target, and 384 lacking revenue model describe the whole IP registry, not just the 103 builder assets. This page does not apply those counts to the 103 rows.
  • Ecosystem-codex "Live" label conflicts with the audit. The ecosystem codex lists Autonomous Builder HQ as "Live" at ~/repos/autonomous-builder/. The audit says the same assets were only Built as artifacts or packs. This demo follows the audit and treats "Live" as unverified.
  • Notion page IDs were not re-verified. The runtime-scoping source cites Notion pages (HQ, Logs, IP Log, IP Build Queue) from a secondary transcript copy. Their IDs were not re-checked against Notion for this build.
  • Layout not eyeballed in a real browser. This page was tested in jsdom for behavior and counts only. Visual layout was not checked in a real browser.
