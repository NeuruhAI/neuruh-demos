  • daiin = of

Herbal image → Pharmaceutical image → surrounding text → labels → recurring token families

When the same plant changes from whole organism to pharmaceutical material, which Voynich components change and which remain invariant?

That can separate likely:

  • identity markers
  • plant-part markers
  • processing markers
  • measurement markers
  • preparation markers
  • generic grammatical material

If we get a stable mapping across 6+ independent plant pairs, that is where we can start translating actual Voynich components instead of guessing at them.

The next experiment

I would formalize the next stage as:

VOYNICH SEMANTIC DIFFERENTIAL ENGINE

The fundamental unit is not a token.

It is:

VISUAL ENTITY │ ├── Herbal representation │ ├── morphology │ ├── labels │ └── surrounding text │ └── Pharmaceutical representation ├── retained morphology ├── altered/compressed morphology ├── labels └── surrounding text │ ▼ TOKEN DIFFERENTIAL │ ┌───────────┼───────────┐ ▼ ▼ ▼ invariant changed introduced tokens tokens tokens

The key question becomes:

What changes linguistically when the visual representation changes function while the underlying botanical identity remains approximately constant?

That is vastly more informative than asking what chol “means.”

What I would extract

For every confidently paired plant:

A. Visual identity layer

Record:

◦ folio ◦ section ◦ illustration ID ◦ plant-part morphology ◦ root representation ◦ stem ◦ leaves ◦ flowers ◦ seed/fruit ◦ vessel/material depiction ◦ degree of compression ◦ retained distinctive features

B. Text layer

For every associated text region:

◦ line ◦ locus ◦ token sequence ◦ paragraph position ◦ label vs running text ◦ token frequency ◦ token position ◦ neighboring tokens ◦ repeated token families ◦ prefixes/suffixes ◦ unusual glyph structures

C. Differential layer

Then calculate:

HERBAL TOKENS ∩ PHARMACEUTICAL TOKENS

and

HERBAL TOKENS − PHARMACEUTICAL TOKENS

and

PHARMACEUTICAL TOKENS − HERBAL TOKENS

But the important part is not merely frequency. We want positional and contextual behavior.

For example, hypothetically:

Plant A

HERBAL: X Y Z A B C

PHARM: X Y Q R

Plant B

HERBAL: X M N A B PHARM: X M Q R

Then:

X = candidate identity/context marker Q/R = candidate processing/function markers A/B/C = candidate botanical-description material

That is an actual semantic experiment.

The six-plus-pair threshold

I agree with the handover's proposed 6+ independent plant pairs, with one important refinement:

They should not merely be six examples that happen to support the hypothesis.

We should deliberately select pairs with different characteristics:

  1. Same apparent plant, strong visual correspondence
  2. Same apparent plant, moderate correspondence
  3. Different plant but same pharmaceutical presentation
  4. Plants with different morphology
  5. Plants whose pharmaceutical representation removes major botanical features
  6. A negative/control pair where correspondence is expected to be weak

That gives us something much closer to a falsifiable experiment.

The really interesting layer

There is another comparison we should add.

Labels vs prose

If the same botanical entity appears:

Herbal label ↓ Herbal paragraph ↓ Pharmaceutical label ↓ Pharmaceutical paragraph

we can ask whether the label behaves like an identity identifier while the surrounding prose carries functional information.

Or alternatively:

label = preparation paragraph = identity/context

Or:

label = dosage/material paragraph = procedure

We don't assume either.

We test them.

This could potentially distinguish several classes of Voynich text without translating a single word.

Token-family analysis

I would also stop treating Voynich words as indivisible strings.

For example:

daiin

should become a structured object:

prefix stem suffix glyph morphology position neighbor distribution section distribution visual association

Then compare families such as:

daiin daiiin dain daiin

against their contexts.

The question isn't:

"What English word looks like this?"

It is:

"What semantic operation appears to remain stable when this morphological family appears across contexts?"

That's the attack surface.

And we should preserve the negative evidence

This is critical.

If a proposed mapping predicts:

same plant → same token

and the manuscript repeatedly gives:

same plant → different token

that is evidence against identity-name semantics.

Likewise, if:

different plants ↓ same token

appears systematically in the same functional context, that becomes evidence for something like:

processing class plant part preparation operation material state

rather than botanical identity.

Negative results are first-class data.

You solved something materially important, but not the Voynich manuscript itself.

What you actually established

  1. The illustrations are not independent pictures. ■ We found evidence that botanical imagery is being reused across sections. ■ That means the drawings participate in a larger information system.

  2. Herbal and Pharmaceutical sections are linked. ■ The same underlying botanical entities can appear in both. ■ This gives us a controlled comparison: same visual entity, different textual/functional context.

  3. Some Pharmaceutical drawings are compressed versions of Herbal drawings. ■ They retain selected morphological characteristics from the larger botanical depiction. ■ That is important because it gives us a way to identify visual identity even when the later drawing is simplified.

  4. The associated text does not behave like a simple plant-name caption system. ■ Where the visual identity persists, the associated lexical material does not simply remain an obvious repeated 'name.' ■ That makes a straightforward dictionary-style interpretation substantially less adequate.

  5. Therefore, the text appears to encode contextual/functional information. ■ The text may distinguish things such as plant part, processing, preparation, material state, measurement, or grammatical relationships. ■ Those categories are still hypotheses.

What you did not solve

We have not demonstrated:

◦ chol = leaf ◦ daiin = of ◦ shol = prepare ◦ otodeeodor = [specific plant] ◦ English translation ◦ Latin translation ◦ A complete grammar ◦ A complete lexicon ◦ The manuscript's underlying language

Those remain unproven.

The actual breakthrough

The biggest thing you solved is the experimental method.

Before, the question was essentially:

"What does this Voynich word mean?"

Now it is:

"When we hold botanical identity approximately constant but change the manuscript's visual/functional context, which linguistic elements change with it?"

That gives us a path to infer semantic roles from controlled variation, rather than guessing meanings from resemblance or frequency.

The next milestone is to do that across 6+ independently paired Herbal/Pharmaceutical entities and see whether the same token families consistently track the same contextual changes.

If they do, that's where we can start assigning actual semantic functions to Voynich components with evidence rather than intuition.

TURN 3: ASSISTANT

There is more. The Herbal/Pharmaceutical pairing is only one layer of what we established.

  1. We established that the manuscript has multiple interacting information systems

High confidence:

◦ Five scribal hands can be distinguished. ◦ There are meaningful Currier A/B writing systems. ◦ Token behavior is constrained by position and sequence. ◦ The manuscript has a distinct label register versus running-text behavior. ◦ Sections exhibit different statistical/structural behavior.

That matters because it moves us away from the idea that the manuscript is simply a pile of arbitrary invented words.

It does not prove that it is a natural language, cipher, or any particular language.

  1. We found actual Herbal → Pharmaceutical correspondences

The concrete examples we had were:

◦ f1v → f102r1 ◦ f37v → f102r1

These were treated as high-confidence visual cross-references.

The pharmaceutical illustration isn't merely "a plant that looks vaguely similar." It appears to compress/reuse selected morphology from the larger Herbal representation.

That gives us something extremely valuable:

ORIGINAL BOTANICAL ENTITY ↓ visual representation ↓ functional transformation ↓ pharmaceutical representation

That is essentially a naturally occurring experiment inside the manuscript.

  1. One of the strongest negative findings was lexical

For f1v → f102r1, we found seven exact shared tokens, but the meaningful repeated sequence was much narrower, including:

chol daiin

Yet the visual entity remains recognizable across contexts.

That creates an important asymmetry:

VISUAL IDENTITY ↓ persists

LEXICAL IDENTITY ↓ does not simply persist

That's evidence against a naïve "every plant has a word/name" model.

This is probably one of the most important things we've found because it constrains what a successful decipherment model is allowed to look like.

  1. Labels appear to be doing something different from prose

We identified a label register that needs to be analyzed separately from paragraph text.

That's a major distinction.

Instead of assuming:

label = plant name

we now have to test:

label ├── identity? ├── material? ├── preparation? ├── container? ├── plant part? └── some other classification?

And then compare that behavior against running prose.

The visual evidence suggested that labels can distinguish plant/container objects, which is another reason not to automatically equate every label with a botanical name.

  1. We established positional information as evidence

The words aren't just bags of glyphs.

Their:

◦ location, ◦ neighboring tokens, ◦ sequence, ◦ section, ◦ illustration relationship, ◦ label/prose status, ◦ hand, ◦ and recurring token families

all potentially matter.

That means a future decipherment can use a multidimensional constraint:

TOKEN │ ├── shape ├── morphology ├── position ├── neighbors ├── section ├── hand ├── label/prose ├── visual entity └── functional context

A proposed meaning that only works because a word "looks like" something is therefore insufficient.

  1. We identified a way to distinguish identity from function

This is the real conceptual breakthrough.

Suppose:

PLANT A Herbal → Pharmaceutical

PLANT B Herbal → Pharmaceutical

PLANT C Herbal → Pharmaceutical

If a token follows the plant, it is a candidate identity component.

If it follows the transformation, it is a candidate processing/function component.

If it follows the plant part, it may be a plant-part marker.

If it appears regardless of either, it could be grammatical/general material.

So we're effectively creating:

WHAT STAYS? │ ┌─────────┼─────────┐ ↓ ↓ ↓ identity function grammar │ │ │ └────┬────┴────┬────┘ ↓ ↓ what changes? │ semantic differential

That is much stronger than attempting a Rosetta-Stone-style word substitution.

  1. We established Prague as a comparator, not an origin claim

There was also historical/network work around Prague, Christian, Borotin, and Schindel.

The conclusion was deliberately constrained:

Prague is useful as a documented comparator/network for investigating the manuscript's intellectual environment.

We did not establish:

"The Voynich manuscript originated in Prague."

That's important because the historical research was kept separate from the linguistic inference instead of allowing a historical theory to dictate the decipherment.

  1. We have a growing falsification framework

This may actually be more valuable than another speculative translation.

The system now has explicit categories:

PROVEN / HIGH CONFIDENCE

Things supported by repeated evidence.

HYPOTHESIS

Things worth testing.

COUNTEREVIDENCE

Things that actively damage a proposed interpretation.

UNKNOWN

Things where the evidence currently isn't sufficient.

That prevents this exact failure mode:

interesting observation ↓ plausible interpretation ↓ repeated as fact ↓ entire decipherment built on it

We've explicitly prevented that.

  1. We have a route toward actual semantic assignments

The current attack isn't:

"Can we translate Voynichese?"

It's:

Can we determine what kinds of information Voynich text encodes?

That's a much more tractable first problem.

Potential categories under test:

IDENTITY PLANT PART MATERIAL PROCESSING PREPARATION MEASUREMENT QUANTITY CONTAINER PROCEDURAL STEP GRAMMATICAL RELATION

None of those should be assigned to specific words until the cross-context evidence supports them.

  1. And this changes what chol, daiin, etc. mean scientifically

This is subtle.

We haven't proven:

chol = leaf

But we have created a testable question:

Does the component represented by chol systematically behave like something that tracks leaves/plant parts across independent visual transformations?

Likewise for daiin.

And shol.

That means the next step can potentially turn:

guess

into:

candidate ↓ 6+ independent observations ↓ cross-context test ↓ positive + negative controls ↓ convergence ↓ semantic assignment

That's the point where we're approaching an actual decipherment methodology.

The honest scorecard

What we've solved:

The manuscript contains a cross-referential visual-textual system in which botanical entities can be tracked across functional contexts, and the associated lexical material does not behave like simple repeated plant-name captions.

What we have not solved:

What the individual words actually mean.

What we now possess that we didn't have before:

A controlled experimental route for finding out.

And that last part is the big one. We have moved from Voynich speculation to Voynich semantic inference.
