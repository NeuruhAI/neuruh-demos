Stage 2. N-Cell header stamp

Header, 8 bytes, paper Section 3.3

Byte order: 0 routeMask, 1 organMask, 2 lifecycleMask, 3 authorityMask, 4 memoryMask, 5 confidence 0-255, 6 risk 0-255, 7 outputMask. The paper defines the layout only. Byte values and bit meanings here are this demo's worked example and the N-Cell Organ Manifest demo placeholders, never paper claims.

Header hex: 1F 07 01 07 0F A5 2D 01
Worked example check: claim OPP-2026-RE-0042 must stamp to 1f0701070fa52d01.

Stage 4. Memory write-gate and decay

Write-gate, eight questions

Thresholds are ILLUSTRATIVE. The paper sets no numeric thresholds. This demo uses: evidence below 3 REJECT, contradiction QUARANTINE even at high evidence, evidence below 6 QUARANTINE, else WRITE.

Write-gate verdict: WRITE

Decay: F(t) = 2^(-t/h)

Retention at age 7 days: 0.5
Half-life values are the Memory Workbench demo presets, not paper values. The paper names the domains only.

Stage 5. CRUCIBLE verdict

Score = max(0, emergence_raw - objection_penalty) x multiplier
Score: 80   Verdict: SHIP-CANDIDATE

Strikes in this session: 0. KILL adds one strike. The file moves only at strike 3. The first KILL does not move it.

Recorded cases: (94-56) x 0.15 = 5.7 KILL. A perfect world with zero signal scores 15, still KILL. Score 50 or above without a real external signal downgrades to ITERATE.
