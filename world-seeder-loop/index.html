A node is a context-poor fact. The intelligence is in which edges get drawn between nodes that were not connected before. The seeder reads the edge graph, detects clusters, and proposes each cluster as a World.

FIG. 3The data contract — the thing that broke

The edges file does not use source/target at the top level. It nests the real data under top_edges — the top 50 of 500 edges. Code reading e["source"] or e["from"] at the top level parses 0 edges. That was the May 12 bug: 500 edges found, 0 parsed.

{
  "date": "2026-05-09",
  "total_edges": 500,
  "top_edges": [
    {
      "from": "ASSET-ID-A",
      "to": "ASSET-ID-B",
      "from_title": "Readable Title A",
      "to_title": "Readable Title B",
      "score": 87,
      "shared_keywords": ["real estate", "lead gen", "scoring"],
      "vertical_match": true
    }
  ]
}

Correct read: data["top_edges"], then e["from"] / e["from_title"] per edge. The wikilink injector builds adjacency from the top 200 edges, max 5 links per node, replacing vault_refs: [] in each node's frontmatter.
