Paste or load receipt v1.0 JSONL, recompute every SHA-256 hash over canonical JSON with the hash field stripped, and see exactly where the chain holds or breaks. The sample chain starts with the real pipeline first-run receipt from 2026-11-14, then two synthetic follow-on receipts chained from it.

How verification works

Receipt format v1.0. For each receipt, the stored hash is recomputed from the canonical JSON (keys sorted, arrays in order) with the provenance.report_hash_sha256 field stripped, so the hash never influences itself. A link passes when the receipt hash recomputes AND its prev_receipt_hash equals the previous receipt hash. The first receipt must start from GENESIS. SHA-256 only. No other hash is used anywhere on this page.

CheckWhat it means
Hash recomputesThe receipt content is exactly what was hashed. Any edit, even one character, changes the hash.
Link matchesThe receipt points at the real previous receipt hash. A swapped or dropped receipt breaks the link.
GENESIS firstThe first receipt in the chain must carry prev hash GENESIS. Anything else is not a chain start.
