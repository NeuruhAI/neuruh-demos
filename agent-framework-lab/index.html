LAB DESIGN DECISION. No source states a scoring rule, a threshold, or a verdict band. The rubric below is this lab's own design: A counts selected components out of 7; G needs the generative pair (public GPT + memory file); E needs the execution path (CRM integration, lead forms, spawn triggers); N needs a stated sample vertical picked; T needs the tools for growth (email follow-ups, spawn triggers, CRM integration). The overall score is the plain mean of the five letter scores. Verdict bands: 90 to 100 Complete stack; 70 to 89 Shippable with gaps; 50 to 69 Partial bundle; below 50 Not execution-ready. 4. Receipt panel (receipt v1.0)

Each run emits a receipt: canonical JSON, keys sorted, hash field stripped before hashing, SHA-256, first receipt chained to GENESIS. The Verify button recomputes each hash in this browser with Web Crypto and checks the chain link, showing PASS or FAIL. 6. Gaps, design decisions, and what this page is not

  • Gap: no dossier gap. A standalone vault dossier exists (MTH-001). There is no standalone A.G.E.N.T. paper or build in the vault; the framework is documented only through the dossier, the collision note, and the three registry rows.
  • Gap: no repo, no runtime, no tests of the framework itself. Nothing here executes A.G.E.N.T.; the builder simulates the packaging steps the registry rows describe.
  • Gap: the second expansion is unlocated. "Autonomous Generalized" has 6 verified GitHub code hits by count, but no file has been read. This page never substitutes Meaning 2 for Meaning 1.
  • Design decision (mine): the five-letter rubric, the overall mean, and the verdict bands in section 3 are the lab's own. They are labeled on the page and are not presented as paper claims or as Jeramie's order.
  • Design decision (mine): the two sample presets (HVAC full stack; Real Estate GPT + memory only) are sample inputs, not facts and not recommendations.
  • What this is not: not the framework, not a verification of any registry claim, not a claim that A.G.E.N.T. executes anywhere, and not a tier assignment. No dollar figures appear anywhere on this page, per the Valuation Honesty Rule.
