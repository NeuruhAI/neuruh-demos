6. Design decisions (mine, labeled)

  
Nothing in this section is a paper claim. Each decision below was made by this build because the sources do not define it.

  
    
    
  • Stage list (six stages). No source defines SAL stages. I defined INGEST, STACK, TRANSFORM, VERIFY, QUEUE, RECEIPT to apply the sourced SAL idea (stacking and orchestrating agent layers) to the content bank and the repurpose engine.
    • 
    
  • Three-layer stack. Fact layer, voice layer, format layer. My layering, chosen so each layer has one job and only sees the output below it.
    • 
    
  • Draft transforms. X takes the first sentence plus the proof link when it fits, hard-truncated at 280 chars. Threads takes the first two sentences. IG takes an 8-word hook plus the full fact. FB prefixes "What this shows:". All four are deterministic string operations on the bank fact, never invented text.
    • 
    
  • Verify checks. Five checks, all computed for real: length, word trace, link count, no live claim when the fact says NOT YET DEPLOYED, no invented dollar figure.
    • 
    
  • Receipt ids. sal-20261114-0001 and up, per session run. This demo's chain is separate from the pipeline first-run receipt rcpt-20261114-0001 in the receipt-chain-explorer; the two chains do not share hashes.
    • 
    
  • Initial cursor 8. Taken from the bank file on disk (cursor_index 8, 2026-11-13 21:55), not from the brief's 08:10 figure, because the file is the fresher record. Both figures are shown on the status board with their evidence.
    • 
  

  
Gaps (honest)

  
    
    
  • No standalone SAL dossier for a content pipeline exists in the vault. The SAL dossier (CORE-002) is a census/collision record, not a design doc.
    • 
    
  • No source defines SAL stages, layer counts, or any content pipeline behavior. The pipeline here is new design, not recovered spec.
    • 
    
  • SAL has no repo, no owner, no runtime. Current runtime: NO REPO. Owner: UNKNOWN.
    • 
    
  • SAL tier is UNKNOWN in the Framework Atlas, not Tier C. The brief's "Tier C concept" framing is not supported by the atlas and is corrected on this page.
    • 
    
  • The vault SAL record is a naming-collision family: Structured Agent Language (AXON SAL Engine) and Signal Convergence Engine are separate concepts and are not used by this demo.
    • 
    
  • Layout was not eyeballed in a live browser by this build; behavior and hashes were tested in Node (see the build report).
