3Decision matrix

Score each option on each axis from 0 to 10. Axis weights default to 1 (equal). Weights are a design decision of this lab, not a DIMEA rule: the source states no weighting scheme. You may change any weight from 0 to 2 in steps of 0.5.

score(option) = (wD x D + wI x I + wM x M + wE x E + wA x A) / (wD + wI + wM + wE + wA)
Ranking: highest score first. Equal scores are a TIE and keep their listed order.

Axis weights LAB DESIGN DECISION

If every weight is 0, no score exists and the lab will refuse to compute. Raise at least one weight.

Pick a case above to open its matrix.

Example scores are sample inputs for trying the lab. They are not facts and not a recommendation.

4Receipt panel

Each scoring run emits one receipt format v1.0 record: canonical JSON (keys sorted, arrays in order), SHA-256 over the canonical JSON with the hash field stripped, chained to the previous receipt hash, GENESIS first. The hash is computed for real in this browser with the Web Crypto API. Press Verify on any receipt to recompute its hash and check its chain link.
